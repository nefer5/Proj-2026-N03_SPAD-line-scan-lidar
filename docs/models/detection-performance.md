# P0：检测判定、置信区间与当前引擎扫参

在已封存的V0.2基线上实施，仍属于A单角通道模型。P1的相关噪声、实测IRF和芯片档案未在本轮实现，TDC死时间仍为0。

## 检测逻辑

原估计器先在**完整接收门**寻找最大峰值评分。评分是背景中值扣除后的高斯平滑峰值除以背景尺度，不宣称它本身是物理SNR。配置脉宽/抖动决定核宽度；不使用目标真值位置限制搜索。真值仅用于Pd/误差评价，局部放大图不影响搜索。

1. 关闭信号，保留当前背景与读出机制，生成独立无目标校准样本。
2. 将每张图的全门最大评分排序，用目标PFA确定上侧次序统计量门限。
3. 只有存在原始距离且评分**严格大于**门限才接受，否则明确“未检出”。并列评分也拒绝。
4. 另用一批独立无目标样本测PFA，其数据不参加门限校准。
5. 含信号重复采集计算检测概率和距离误差。误差棒仍包含所有原始采集，不因未检出而剔除计数样本。

校准规则：n为校准样本数，α为目标PFA，选择升序排列中第`ceil((n+1)×(1−α))`个评分。秩超过n则拒绝配置。在模型独立同分布、交换性成立时，该规则控制边际超阈概率；**不保证某次固定门限的实际PFA恰好等于目标值，也不是实物认证**。独立验证和区间不能省略。

## 指标口径

| 指标 | 分子 / 分母 |
| --- | --- |
| Pd（命中容差） | 通过门限且距离误差≤配置容差的次数 / 含信号总次数 |
| 触发比例 | 任意距离通过门限的次数 / 当前工况总次数 |
| PFA | 无目标验证中任意距离通过门限的次数 / 无目标验证总次数 |
| 失败率 | 1−正确距离比例，包含未检出和接受错误距离 |

PFA针对**一次完整采集、整接收门**，不是每bin概率。区间采用精确双侧Clopper–Pearson二项区间，依据[NIST说明](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)。区间针对固定校准门限下的验证概率；零次虚警时上限仍大于0。零信号预算不报告Pd，含信号统计0次时Pd及区间为空而不是0。

距离、偏差、精度默认只用通过门限的估计；必须同时看有效/总次数及失败率。原始未过门限的距离保存在`metrics.raw_estimated_range_m`和调试`raw_trial_estimates_m`中。

## 各重复次数

- 24（`readout_expected_trials`）：原有噪声曲线和内部读出均值，不用于设置检测门限。
- 40（`monte_carlo_trials`）：测距评价与观测误差棒，包含首次蓝柱。
- 99（`detector_calibration_trials`）：独立无目标门限校准。
- 100（`detector_null_trials`）：独立无目标PFA验证。

默认目标PFA=0.05、置信水平95%，只是探索设置，不能据此声称百万分之一的虚警率。目标越小，需要越多样本及计算预算。

四个原有随机流编号保持不变，校准/验证使用独立spawn key 4/5。检测开关或样本数不会改变首次观测或解析GT。JSON审计保存配置、门限、校准/验证评分和随机流标识。

## 性能扫参

`POST /api/performance-sweep`接收完整配置、轴和离散值，支持距离、太阳照度、累计脉冲数。界面预设来自algorithms.yaml，可手动修改。

每点调用同一`simulate`，保留所选SPAD/TDC、OR/符合、门控、死时间和容量，并独立校准门限。输出Pd/PFA及区间、失败率、偏差、精度、有效/总次数、理想信号候选、混合记录均值、独立种子及配置指纹，可导出JSON。原有理想距离预算曲线保留作无pile-up对照，不当作所选读出模式的最大测距。

区间是逐点区间，不是同时置信带。精度是接受条件下的统计，需同时看失败率。用每点seed和参数单独运行可复现该点。整个批次开始前验证全部参数和聚合资源上限，不静默降低样本或切换模型。当前仍为有界同步API，没有实现P2后台进度/取消。参数或列表修改后，旧扫参结果会标记过期。

## 模型边界

这是模型匹配背景下的校准，不等于真实未知背景自适应CFAR。太阳瞬态、其他LiDAR脉冲、背景谱误差、真实IRF/模板失配仍需后续工作；不同芯片读出拓扑与极低虚警性能不能仅由此模拟确认。
