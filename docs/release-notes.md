## 0.6.15.dev0（2026-10-18）

本版收录公共后台与领域默认配置两阶段重构、五平台默认值写回、启动器修复和本阶段前端优化。配置来源集中于defaults.yaml schema 2；读取/组合/写回使用共同归属，旧快照及公开工况协议保留兼容。

界面统一SPAD/预算/A/B/C入口与当前禁用态；优化1080P文字、浅色分组、三维坐标叠层及横纵虚线辅助网格。输入和结果采用简洁数值格式，未编辑参数、计算与完整导出保留原始精度。详细验证见[数值及分层证据](../artifacts/frontend-precision-hierarchy-20261018-205020/README.md)。

状态：本阶段已实现并自动自验；真实公司显示器的体验、器件符合性及既有模型人工验收边界保持独立。C后续电学和C/预算调度整合按用户要求暂缓；列间完全复位等未完成事项继续列于[路标](roadmap.md)，不由版本升号关闭。

### 数值精度与浅色分层

普通数值最多两位小数，极小/大数使用科学记数法；输入的原始精度独立保存，悬停可查看完整数值。浅色页面、主面板、参数模块、子组与输入建立清楚层次；容器实线边界与淡色虚线图表网格分开。
