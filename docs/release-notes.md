# 研究版本记录

当前版本：**0.6.7.dev0**。版本号描述软件实现，不代表实测器件符合性；当前状态见[路标](roadmap.md)。

## 0.6.7.dev0

- slot预览改为有效扫描内的真实时间位置；局部角域坐标轴移至左侧/底部；源波形旁增加单通道全信号链能量/光子柱图。
- SPAD输出新增直方图/range载荷、chip/MIPI link/data lane拓扑、平均带宽、突发缓存与帧内传输参考；MIPI进入逐发/帧时序图。芯片包头与下游总列头分开。
- 距离参考新增理想IRF抖动卷积、TDC/gate积分的面积/峰值/脉宽及泊松Fisher统计精度界；手动/CSV实测点独立保存，仅作对照，不自动标定。

## 0.6.6.dev0

- 数字展示最多两位小数，小量用科学记数法；未编辑的表单、计算及导出保留原始精度。
- 均分预算改为代表通道示例，时序按帧、完整slot、有效收发段和单发纳秒窗口分层。光子链路使用单通道一次发射，分gate、回波中心脉宽窗及交集；公共脉冲核心计算源光能及窗口份额，高斯FWHM窗与全脉冲能量区分。
- 三维细节图移至主图下方横排，增加坐标刻度、H角宽与列间距ΔH对照及V倒像关系。

## 0.6.5.dev0

- 按画板整理收发支路，保留整帧HFOV×VFOV与单列放大，右侧加入全角域、单通道对照和V成像细节；单通道统一mrad/deg双单位、H×V摘要及光谱折叠层级。点云数量下只读输出H/V采样角间距；Rx显式V造成包络差异时提供解释和跟随操作。

- 系统预算采用均匀独立角通道，单通道功率/能量/V全角由总量与线数派生，Rx单通道H/V独立输入。模块折叠摘要、参数双向定位、通道和扫描列选择、正交视图及硬件H=-X_Z展示转换已实现。旧草稿备份及v3迁移可审计；B/C核心坐标与人工验收状态保持原定义。见[指南](guides/system-budget.md)。

## 0.6.4.dev0

- 系统预算接入本地Three.js：Tx/Rx角域与角密度、展开光源/入瞳/SPAD阵列、表单双向高亮及可暂停讲解动画。源数据来自同次Python预算，旧图/草稿状态分开；明确非等比例、非完整光线追迹。[操作说明](guides/system-budget.md)。

- B/C及系统预算用全Tx等效平均功率输入，默认280W；按用户确认的E=P×脉宽（高斯FWHM）换算能量。旧能量输入在兼容层迁移，混合新旧输入报错。
- 背景使用独立Rx角网格；信号超出显式Rx域记为接收损失，域内响应表缺数据仍报错。历史算法快照标记legacy_tx，不把历史结果悄悄解释为新算法。
- 预算新增VFOV、Tx H全宽、独立Rx边界以及Tx等角V分区和Rx物理V组两张表；两者索引不冒充一一对应。[验证记录](../artifacts/tx-rx-domains/README.md)。

## 0.6.3.dev0

- 2026-09-28：正式平台增加统一深/浅色切换，跨页保存偏好；覆盖表单、公式、SVG和Canvas，不重新执行仿真或改动结果。[验证证据](../artifacts/theme/README.md)。

- 基础滤光片四种形状增加带外透过率，峰值与带外基底分开；零漏光保留旧行为，非零时覆盖提供的源光谱，并明确导入Rx的已知波段约束。
- 无色差构造Rx以精确空间/光谱外积减少计算与存储，保留全部积分节点和可重建数据。
- 太阳与其他环境光新增每time_bin候选计数：PDE/FF后计数率乘bin时长，不额外统计、不乘N/M。全阵列或单角通道范围明确标注。
- 折叠小标题加粗，旧结果只读增加显示信息。已验证零漏光旧任务记录不变。
- 文档整理：新增文档目录、架构决策与偏好、运行数据说明和C人工验收模板；按设计、模型、指南、验收、参考与历史分类，同步相对链接和递归公式校验。
- 明确下一轮R01–R05：Rx/Tx角域分离、C人工精细验收、命名统一、参数/定义/逻辑共用审计、UI统一。

证据：[带外漏光与每bin计量](../artifacts/filter-leakage/README.md)。本次提交前验证结果见[发布前核验](../artifacts/release-0.6.3/README.md)。
