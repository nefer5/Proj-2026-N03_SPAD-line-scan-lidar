# C 列级扫描工作台

正式入口为 `/system/scan`（别名 `/system/columns`）。旧周期任务继续在 `/system/scan/legacy` 或原任务链接查看。新配置/任务kind为`columns`，配置文件schema_version为4，不把设计草案自动当作正式配置。

## 默认目标与使用顺序

高层默认值只定义于`config/defaults.yaml → experiments.system_targets`：10 Hz、HFOV 120 deg、扫描时间利用率66.7%、每帧1000列。Python生成100 ms帧周期、66.7 ms可分配扫描时间、66.7 μs列目标和0.12 deg均匀角格参考。前端没有另一套预算公式。

1. 在高层设置目标，下发并更新列计划。下层不能独立放宽T_slot；列内发射越界会明确报错。
2. 配置Tx/Rx、场景、SPAD和电子读出。H×V默认2×16；V表示线数，所有H路都参与物理计算和整列数据量，切换显示H路不会关闭硬件。
3. 在逐发列表编辑`time_offset_ns`和`energy_nj`。null能量显式继承Tx完整单发能量，数值覆盖本发，零能量是暗触发。列表按列重复，不自动排序、裁剪或补齐。
4. 可选择完整帧，或显式列区间。默认强环境光整帧超过事件资源限额时，可运行“选中两列实验”保留物理背景，或加载具名快速示例。局部实验只激励选区与有限前驱预热源；不是完整帧记录的裁剪，也不代表完整帧探测表现。未知区域不填成零。
5. 配置DSP/MIPI并启用资源计算。未给出的耗时默认未知。填完整后才生成数值流水线；按数据量计算时净速率/格式/列头必须明确。
6. 运行后台采集。结果保存完整配置、算法、时间、版本、seed、指纹和原始记录；可取消、刷新找回、选择结果帧/列/通道、重放分箱和导出。

## 时钟、归属和门

列ID定义输出列；cycle定义名义触发或无光列锚点参考。若首发延迟或列表为空，列起点的锚点建立参考时钟。SPAD恢复与TDC忙碌贯穿整次实验，容量计数依显式参考周期管理。

`per_pulse`模式取所有名义门的并集；重叠门不重复生成背景。同一参考内的门碎片维持同一容量周期，在实际门关闭处结束OR/符合瞬态。`column`模式整列开门，原门起点/宽度用于TDC码与分析范围。`free_running`时门外背景仍影响器件状态，读出受记录门约束。

原始记录保留绝对时间、参考相位、列ID、触发ID、通道、TDC及量化区间。门并集可能保留前一触发的门，因此相对配置门原点的TDC码可为负；参考相位本身仍属于该参考时间区间。源身份不参与记录归档或寻峰。

选区采用范围内激励及配置的有限前驱预热，光子随机流是该实验的独立实现。观测边界外候选/尾部明确计数，不重新归一化。记录门未被观测范围完整覆盖的列单独标记。

## 扫描光学与时域尾迹

世界扫描使用三维绕垂直轴旋转。Rx效率/PSF查表输入是接收机局部角；120度全局HFOV不会作为局部小角度输入。光学背景仍是Rx局部角域内的均匀平稳谱；没有臆造真实天空/场景纹理。

每发能量独立缩放相同B光学能量核。接收效率、滤光、完整像素PSF份额、PDE/FF各只应用一次；阵列外能量保留为损失。高斯模型使用独立f_H/f_V及倒置映射；数据库使用实际响应，不用未生效焦距替代它。

可选尾迹将一部分完整能量作非负指数延迟，支持高斯或矩形基底。采样和展示使用同一Python时域函数。**光学姿态仍按脉冲/回波中心求值，尚未解析长拖尾期间的连续扫描拖影**；不能据此声称已经完成任意长时间光斑运动的精细耦合。

16线阵列不会自动扩大原有Tx/Rx局部角覆盖；当前构造光学可能只照亮部分行。采样行列数、光学分辨能力、时间量化与测距精度分别解释。

## DSP、MIPI和缓冲

双缓冲是默认架构。缓冲在列开始预留，MIPI完成后释放。DSP在所需记录门完成且列结束后启动；serial模式一列完成后接下一列，pipeline模式另需给启动间隔。全部线阵行按列并行，不将DSP时间乘线数。

MIPI位于DSP后，单链路FIFO。duration模式使用整列耗时；payload模式支持固定点结果、分析直方图或实际事件数据量，使用净载荷速率和明确列头。原始事件模式在缺少完整计划的采集数据时保持待计算。直方图位宽目前仅预算长度，不实现饱和/截断编码。

扫描开始时刻保持高层计划。没有空闲缓冲时按配置丢列或报错，不通过延迟扫描掩盖超限。离线探测记录仍保留，丢列不进入交付点云。局部探测实验与全系统资源计划分别标注：只有被仿真的列有探测结果，固定格式排程可以覆盖整个系统计划。

初始输出缓冲为空，状态跨帧延续；排程是给定硬件约束下的模型结果，不是实测延迟。应结合启动间隔、稳态吞吐、完成期限和缓冲占用判定目标，不能简单相加采集/DSP/MIPI时间。

## 结果与统计

不创建帧×列×通道×时间的巨大稠密数组；完整事件保留，逐列重建、按需生成所选直方图。显示分箱只能是保存TDC分箱的整数倍，重放不重新采样。

多次采集与激光关闭参考保存独立seed和记录。每次选择/重放后再计算各时间分箱的最小/最大范围、噪声样本均值及原始距离样本标准差。1次采集没有误差棒；0次纯噪声运行没有伪造期望曲线。

理想信号参考是抖动、恢复和数字读出之前的候选数，包含已建模源脉冲、预热和门并集。它不是最终数字记录的均值。过大的参考工作量明确报错/不可用，不默默近似。

距离与点云是全分析窗寻峰的原始估计；有数字不等于成功检出。没有C专用Pd/PFA标定，也没有用源真值修正测距或角标签。条件RMSE会包含弱信号/噪声峰；源真值只用于后验审计。点云坐标为前向投影角约定，非法/后向方向保留无效标记，不输出伪造XYZ。

## 模块与可审计性

- `scan/planning.py`：高层目标与预算；通过`SimulationConfig.system_targets`加载/合并/校验YAML。
- `scan/column_config.py`、`column_schedule.py`：列计划、触发与门策略。
- `scan/column_optics.py`：世界/接收坐标及B光学核组合，缓存只复用完全相同的响应，不近似光学。
- `timing/gates.py`、`spad/readout/gates.py`：通用门并集协议与共同读出核的门命令。
- `spad/acquisition.py`、`spad/device`、`spad/readout`：A/B/C共用器件/读出状态；被动轨迹不消耗随机数。
- `scan/transport.py`：独立的数据资源排程；不改光学或器件记录。
- `processing/column_reconstruction.py`、`reporting/column_view.py`：真实记录处理和按需显示。
- `web/columns.js`只采集配置与作图；曲线编辑、系列图和直方图分别复用公共组件。

公式、定义与光子步骤统一来自三个共享YAML文件，`docs/photon-budget.md`由脚本生成并同步检查。资源阈值在`config/algorithms.yaml`，没有自动降采样、关闭光源或裁剪配置来绕过限额。
