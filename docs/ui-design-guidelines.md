# 仿真平台界面规范与用户偏好

本规范归纳自B平台的实际设计反馈，适用于A/SPAD/B/C及后续工作台。它约束本项目，不修改全局规则。

## 信息组织

1. 按直观的物理模块分类：Tx、场景、Rx、SPAD、读出、环境光、采集；C增加扫描机构、同步和重建。源码职责、配置类型、YAML和界面名称尽量对应。
2. 参数按真实关系组织：H/V、x/y、最小/最大值、中心/宽度、帧/角bin/通道等成对成组，避免散落的长字段清单。
3. 一级标题用青色突出；全折叠/展开用小按钮。常用项可见，高级项、解释和审计分层展开。
4. 共有参数继承已有默认值，不为了演示另设隐含默认值。专门演示工况必须具名，明确显示改了什么。

## 操作方式

5. 控制项靠近对应图形。拖动便于探索，同时提供精确数值输入，不能只靠鼠标微调。
6. 多通道、多帧、多角度先选择后展示，优先分面；不把大量曲线堆在一张图。共享时间窗口时明确说明同步范围。
7. 橙色观察窗口与蓝色直方记录明显区分；观察窗口、物理接收门、数字重放和重新采集是四个不同操作。
8. 任务记录占用小面积，保留进度、取消、历史查看。主要空间用于参数核对和结果分析。

## 科学表达

9. 空间图右正左负、上正下负，保持真实坐标纵横比；二维图有数值色标、单位、坐标和二维标签。帧/通道索引不冒充物理角度。
10. 页面开头有可展开的计算链路、示意图和概念定义。参数可视化独立折叠，保留初版的波形、滤光片、太阳谱、环境光、PDE等图。
11. 区分入瞳光子、探测面光子、候选雪崩和混合记录；明确PDE/FF、能量参考面、全轴尺寸、FWHM/σ等定义。
12. 直方图统一蓝色观测、青色理想解析参考、橙色噪声期望和样本范围误差棒。统计层缺少对应数据时明确标为不可用，不伪造、不换成另一种统计口径。
13. dB必须说明比较量和参考值：能量/功率比取10倍对数；幅度平方对应功率时幅度比才取20倍对数。零值和未定义分开显示。
14. C明确区分计划轨迹、实际光学指向、编码器标签、真实发数和分配发数；距离、点云的未标定检测状态须保留。

## 实现与验收

15. 前端负责输入和绘制；物理公式、波形、统计、角度归属和点云由公共Python核心提供。图形组件与整段处理逻辑复用。
16. 当前参数、参数预览、已采集结果、重放结果分别标识；显示配置指纹和来源，改输入不改历史记录。
17. 支持配置/数据导入导出和普通刷新；资源内容指纹、旧配置迁移、有效输入模式等行为保持一致。
18. 复杂界面先用可点击原型确认，再接真实计算；自主验证表单、联动、图形和数值，保留源码、结果及截图快照供复查。
19. 多通道选择与物理位置相互联动：列表和示意图共享选择状态，标清零起始编号、H/V 方向与实际坐标；光斑可以半透明叠加，选中边框应与光强颜色区分。空间图、统计图始终绑定同一个结果工况，不跟随尚未采集的参数草稿改变。

整体偏好是：物理含义清晰、结构紧凑、可精确控制、可核对和复用。视觉设计服务于建模判断，不掩盖数据来源或模型限制。
