# 系统预算：单方案与基准对比

入口：`/system/budget`，A/B/C顶部导航均可进入。定位为VCSEL线阵、转镜和SPAD硬件的确定性预算；不包含后端点云算法，也不替代实际器件或整机验收。

## 使用流程

页面顶部新增“三维含义”示意区。左键拖动旋转、滚轮缩放；可切换透视、角域正视和探测器视角。点击表单参数会高亮对应部件并显示当前有效工况的解释；点击三维部件、悬浮标签或部件按钮会定位关联表单。颜色和几何都来自同一预算结果，未计算或非法草稿会保留旧图并显示待更新状态。

“传播示意”可播放/暂停光源→目标→Rx→SPAD的讲解动画。动画速度与粒子数量没有物理含义，不是实际光速、蒙特卡洛事件或完整光线追迹。Tx/Rx没有共同采样角时不画返回路径；光源功率为0时关闭传播动画。图中转镜表示局部角度原点，另设独立缩放HFOV扫描扇区。

角域共用原点便于比较，不声明实物收发共轴。纵向距离与横向投影分别缩放，画面标明放大倍率；H/V横向比例一致。光源、入瞳与探测器采用展开示意，器件位置不作为已知尺寸。探测器网格使用实际像素边界，颜色来自独立单通道B光学核心的探测面能量；大型阵列可按显式显示限额转为通道组或仅轮廓，计算采样不变。

1. 通过项目启动器启动服务，打开系统预算页。初始光学/器件/门参数继承B的当前默认，系统目标继承C的高层目标。当前全Tx单脉冲等效平均功率默认280W、Tx光学前；高斯用FWHM等效时长，2ns对应560nJ。Tx的H归一化域全宽默认2mrad，V全宽联动VFOV。VFOV为独立系统目标，初始示例10°，不是实物指标，不再继承B角域。默认光学是构造样例。
2. 核对目标帧率、HFOV、时间利用率和列数，再调整每列发数、发射间隔、单发能量和接收门。
3. 复位时间、电光效率、功率限额、直方图位宽/列头/净速率默认未知。按实物条件填写；不要用零表示未知。显式填写零复位表示理想假设。
4. 点击“保存为对比基准”，再修改参数。输入修改后显示旧结果提示，成功计算后切换到新结果；计算失败保留旧结果和明确错误，不将它标成当前参数结果。
5. 使用“导出工况”保存可导入的配置；“导出完整快照”保存完整结果、工况、算法、共享公式定义、时间、版本、指纹和可选基准。高级JSON支持未在简表展开的所有B参数。
6. “送入B验证”将当前成功计算的静态光学/器件/采集配置送入B；不会触发采集。系统目标、复位、电热和PRBS预算不属于B，未随之执行。C可从顶部导航进入，需明确逐发计划及实际扫描几何。

## 默认值与计算入口

- 配置总入口为 `SimulationConfig.for_experiment('budget', overrides)`；组合B工况、系统目标、预算假设和现有C transport配置。所有默认只读自 `config/defaults.yaml`，先校验完整默认，再合并用户覆盖。
- 新增假设位于 `experiments.budget`，未测量数值为 `null`。光谱使用现有Curve输入组件及Python积分，不维护第二组光谱标量。
- `system_budget.py`复用 `uniform_column_budget` 和B的 `project_illumination`。展示公式维护在 `formulas.yaml` / `formula-notes.yaml`；光子链路复用 `photon-flow.yaml` 的spatial定义。
- 时间图输出行数受 `algorithms.yaml` 的 `budget_timeline_max_pulses` 约束；截断只影响绘图，所有发数仍参与预算。
- 表单枚举按字符串提交。JS只收集、显示及做单位/绘图坐标换算；预算运算在Python中完成。

## 计算口径

| 项目 | 当前口径 |
|---|---|
| 时间 | 有效扫描时间均分到各列；列内等间隔发射。包络止于最后接收门或脉冲FWHM右端较晚者，再计列间复位。复位未知时仅给未计复位余量，不给最终可行结论。 |
| 光能与功率 | 全配置Tx角域内、Tx光学前能量；只在计划列中发射。平均功率按每帧列数、每列发数和帧率计算，不直接使用列内PRF作为整帧平均频率。 |
| 光子 | B静态、单距离、大朗伯目标；独立同型角通道合计的单发/单门链路。单列信号按本发门内光学份额累计，背景按总开门时间累计，单独列器件噪声。 |
| 扫描 | 用高层HFOV和有效扫描时间给出匀速光学角速度、首末发角位移和飞行期间转角；并未将这些量用于修正静态光子数。 |
| 电热 | 用显式电光效率估算发光器件电输入和非光损耗；不含驱动、电机、接收芯片等功耗，不推断结温。 |
| 输出 | 计算原始直方图位宽、列头和净载荷需求，核对无积压持续输出的单列传输时间。该预算独立于C的transport启用开关；不模拟DSP、缓冲调度或计数器饱和。 |
| PRBS | 独立候选方案：每个开码片发一个与主方案同能量短脉冲，仅计算周期、能量、开码片比例、名义周期距离和扫描位移。不替换主方案，不生成码或验证相关收益。 |

候选雪崩已含PDE/FF；最终混合记录以及死时间/读出损失为未评估，不能用候选数冒充。背景原始光子数标注实际积分波段。

## 边界与状态

- Rx背景使用独立Rx角域；域外设为不接收，域内数据库缺覆盖报错。固定Rx/环境时改变Tx域不改变背景。该边界为显式模型假设，真实收光范围仍需实测核验。
- 不运行随机事件采集、Pd/PFA或测距估计。无探测距离达标、抗干扰增益或眼安全结论。
- 光子累计不含扫描造成的空间截获变化、其他脉冲跨门尾部、门外背景对自由运行恢复状态的影响。
- 时间包络不含高斯无限尾；首发中心作为时间原点，真实驱动建立、前沿以及列末锁存等开销需专项建模。C列间复位仍是待实现机制。
- 默认TDC零死时间等现有假设保持可追溯；芯片参数是否满足真实硬件须另行确认。
- 当前为已实现、自验；用户人工验收待进行。验证记录见[系统预算证据](../../artifacts/system-budget/README.md)。

## 刷新与恢复

默认值每次从API重新读取；“重新加载默认”重新请求YAML，保留已有对比基准。当前草稿和基准快照保存在本浏览器的 `spad-hardware-budget-v1`，不覆盖其他页面草稿。基准保留保存时版本与指纹，不随刷新重算。

无法解析或版本不匹配的旧草稿会明确报错，并保存在 `spad-hardware-budget-v1-rejected` 供恢复；随后显示当前默认。不会静默接受旧版本。页面静态资源带内容指纹，开发服务禁用缓存；普通刷新即可使用新版本。

## 0.6.5独立角通道与界面优化

系统目标输入VFOV与V角通道数；H读出固定一路。Tx空间分布为均匀分布，时间波形仍可选高斯或矩形。全Tx等效平均功率按V线数均分：单通道功率=P总/NV，单通道能量=E总/NV，Tx单通道V全角=VFOV/NV。默认16线、280W、2ns时，每通道17.5W、35nJ。VFOV的独立YAML初始示例为10°，请按实物填写；禁止从B样例角边界推定系统VFOV。

Rx输入为**单个角通道**H/V收光全角；V留空跟随Tx派生角，显式填写则独立。整阵列V包络=(NV−1)×角通道中心间距+Rx单通道V全角，不假设收光角域恰好拼接。单通道内SPAD数量由H/V binning乘积派生，与LiDAR线数不同。

本页对单通道复用B公共光学核心，再按同型独立通道累计；完整审计快照包含single_channel配置及中间量。没有跨通道PSF串扰或整阵列光路耦合，不可用重复单通道结果替代B全光斑验证。导入光学数据库不支持此独立通道预算，需进入B研究。

参数按系统、Tx、场景、Rx、SPAD、环境和高级选项分组。系统目标中的HFOV/VFOV成对显示；点云数量一组包含slot数量、线数/通道数，右侧只读显示单通道V全角（mrad），下一行注明等价deg，说明提示中注明VFOV÷线数。Tx的V全角同步使用这一结果；全部收起/展开后保留已计算摘要。修改期间摘要及图仍属于上次有效工况，待计算提示明确区分。

三维图可选透视、正交正视H/V、俯视X/Z、侧视V/Z以及探测器视角。红色Tx、蓝色Rx；选择V角通道会同步标出Tx/Rx单通道区域和SPAD分组。选择扫描列更新独立缩放HFOV扇区参考线；主角域保持局部坐标，未用动画更改物理预算。功能传播顺序为光源→转镜→目标→转镜→Rx→SPAD；器件仅为展开关系示意。

硬件示意沿用用户Zemax坐标：+H对应−X_Z，+V对应+Y_Z，+Z_Z朝场景。现有B/C计算坐标x_m仍随+H、像面使用反向映射；两套坐标通过展示转换衔接，没有翻转历史数值模型。

导出schema_version为3。旧v1/v2工况保留功率/能量，将旧Rx全阵列V宽除线数作为单通道宽，并显式采用H一路/空间均匀的新口径。浏览器原草稿备份在spad-hardware-budget-v1-before-v3；旧基准保留原版本且标记不能直接比较新旧光学性能。

优化验收记录见[界面与交互证据](../../artifacts/budget-optimized/README.md)。当前已实现及自验，用户人工验收待进行。


## 全视场、局部分析与单位

主图提供“整机全视场”和“单列角域”两个范围，正视/俯视/侧视相机独立选择。全视场用HFOV柱面与VFOV覆盖网格表示整帧；列内Tx/Rx和选中V线同时高亮。为可读性全视场V可额外放大，倍率明确注明；局部H/V角域保持同比例。V线及H列网格仅按algorithms.yaml既有显示采样限额抽样，实际通道数/slot数不变。

按用户画板的俯视关系，VCSEL位于转镜后方Z支路，Rx入瞳与SPAD位于侧向X支路，探测面垂直于该接收支路。它们是功能位置，没有新增机械间距或镜面反射求解。

右侧保留整机H/V角域、当前通道的Tx/Rx真实比例对照与V成像至SPAD分组图；整机角域中点选线带可更换通道。单通道角度首先显示mrad，并在下方附等价deg；Rx V输入显示mrad，配置文件保留原v_width_deg键，页面仅做单位转换。Tx/Rx折叠摘要为H×V mrad；SPAD摘要分行列出H×V通道与H×V binning。光谱子项通过缩进、较小字体和次级颜色区分。

Rx V显式设置时不会随线数或VFOV修改，因而与Tx单通道V全角及整列V包络可以不同。对照图显示当前差异及原因；“Rx V跟随Tx”将配置显式设为null，随后公共核心计算采用Tx单通道V。不会为视觉重合而更改输入。

点云数量下方增加只读H/V自动角分辨率：H=HFOV/slot数、V=VFOV/线数，以mrad显示并附deg。这是采样角间距，不代表光学分辨能力，也不是Tx/Rx单通道角宽。


## 0.6.6显示精度、分层时序与单通道窗口

人类阅读的数值最多两位小数，非零小量（绝对值低于0.01）及大数用科学记数法。表单显示舍入，未编辑的字段仍提交原数；主动输入按用户输入提交。原始JSON、CSV/手动采样数据及导出保留完整精度，不改变数值核心。均分通道表只给任一代表通道，完整角格数组保留在审计结果中。

时序区分一帧扫描/非扫描时间、slot索引抽样、完整slot的发射/gate/回波/余量、有效收发段放大，以及单发回波中心的纳秒细节。抽样slot示意不是等比例时间轴；单发可选发数。复位未知仍不给最终时间可行结论；高斯尾部不假定有限结束。

第三部分以单角通道、一次发射为主：一个实际gate、以回波中心为中心的等效脉宽窗（高斯FWHM或矩形实际时长），以及二者交集。gate之外的脉宽窗为窗口参考，实际gate记录须看交集；它们都不是数字读出后的最终记录。背景/器件噪声按各自窗口时长积分，信号按同一公共脉冲核的归一化时间份额积分。原始背景光子始终注明积分波段。

单通道源光能给全脉冲能量、脉宽窗口能量、窗口份额、该窗口实际平均功率和波形峰值。高斯FWHM窗约占76.10%总脉冲能量，矩形持续时间窗占全部能量；既有E=P_eq×等效脉宽的输入口径不变。窗口积分及功率曲线均由Python输出。新增绘图采样数量、视窗宽度和frame预览slot数量写在algorithms.yaml，随完整审计导出。

细节图移到主三维图下方横排，不再嵌套侧栏滚动。H图同轴对照Tx/Rx角宽、相邻列照明和ΔH采样间距；Rx角宽/ΔH仅为角宽比，不代表独立分辨单元或已仿真的跨列串扰。V像面图给视场角、Rx光学和SPAD Y坐标，分组/倒像是独立通道模型的功能示意，不是完整光线追迹。验证见[0.6.6证据](../../artifacts/budget-windows/README.md)。


## 0.6.7电学输出与距离参考

输出格式下拉分别选直方图和range固定记录。每条V线一芯片为初始拓扑；可修改每chip角通道数、每MIPI link汇聚chip数及每link data lane数量。D-PHY有独立clock lane，clock不计载荷；C-PHY是trio，不能套本表lane口径。MIPI采用用户给定lane比特率和净效率，不从PHY时钟再乘DDR，也不使用标准最新版上限冒充芯片能力。见[MIPI D-PHY定义](https://www.mipi.org/groups/d-phy)、[CSI-2物理层说明](https://www.mipi.org/specifications/csi-2)。

芯片包头在electrical.chip_header_bytes，按chip每列计。既有transport.column_header_bytes仍为全列下游头，不冒充chip头；协议/切换空隙另外由净效率声明。直方图可列内累积一次或逐发合并列包；range按每点返回记录数×记录长度计，不预测实际range算法或丢记录压缩。示例16bit计数器、8B/range、16B/chip列头、2lane/link、1500Mbit/s/lane、80%效率只在YAML定义，必须按实际芯片替换。

计算输出chip/link数量、每列/帧载荷、每link及总带宽、扫描期需求、每列串行传输、帧内完成时间和仅链路的FPS上限。列包在接收包络结束+固定就绪延时后发出，假设就绪流水；没有额外建模串行DSP启动间隔。固定服务的最忙链路用FIFO顺序解析计算，缓冲峰值包括发送中包。平均足够但slot期间积压时可依靠扫描外时间排空；端口数和缓存未知则不判实际可部署。MIPI时序并入主帧/slot图，抽样包只表示真实时间位置，浅框不表示全程忙。

预算不分配完整hist数组，时间bin容量单独受budget_max_histogram_bins限额；实际A/B/C仿真资源限额不修改。超出B运行限额时禁止直接送入B并显示原因。距离参考仅算IRF支持区的Fisher信息，ROI/距离点数/实测点数均受算法YAML资源策略约束。

理想距离曲线给信号/原始总直方图面积、峰值每bin、IRF FWHM和泊松候选直方图的统计精度界。激光脉冲与器件/其他高斯抖动卷积，按实际TDC和gate积分。以B光学核心当前单通道信号作固定反射率、大气和光学条件下的1/R²缩放，幅值未知作为Fisher干扰参数、背景已知。参考原理见[光子噪声下测距CRLB](https://opg.optica.org/ao/abstract.cfm?uri=ao-47-28-5147)。本实现未加入[死时间导致的信息损失/耦合](https://pmc.ncbi.nlm.nih.gov/articles/PMC12526853/)，不宣称复现该论文或标定真实器件精度。

实测手动/CSV分别保存，仅当前模式生效。distance_m必填，其余area_counts、peak_counts、fwhm_ns、range_std_mm、range_bias_mm可空；单次列测量（多发累计）的面积/峰值口径应选择扣背景或原始总计数。不得用虚构示例点当实测。只画对照，不自动拟合或改正距离；门/分箱质心参考偏移也不是实测校正量。
