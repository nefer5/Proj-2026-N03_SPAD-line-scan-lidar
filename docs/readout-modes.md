# A版数字SPAD读出模式

本轮实现7类可参数化数字dToF架构，外加1个理想解析参考。分类参考 [Incoronato等，Statistical Modelling of SPADs for Time-of-Flight LiDAR，2021](https://doi.org/10.3390/s21134481) 的single-hit、multi-hit、coincidence、gating与multi-TDC讨论；这里的离散事件实现与仲裁约定是本项目明确选择的模型，不代表所有芯片都采用相同细节。

| 模式ID | 逻辑 | TDC/容量 | 时间戳约定 |
|---|---|---|---|
| independent_first | 每SPAD独立输出 | 每SPAD一TDC，每周期1个 | 有效雪崩到达 |
| independent_multi | 每SPAD独立输出 | 每SPAD一TDC，每周期可多次 | 有效雪崩到达 |
| shared_first | OR脉冲汇合 | 共享一TDC，每周期1个 | OR上升沿 |
| shared_multi | OR脉冲汇合 | 共享一TDC，每周期可多次 | OR上升沿 |
| shared_multitdc | OR脉冲汇合后分配 | 最先可用TDC，平局选低编号；容量按每TDC每周期 | OR上升沿 |
| coincidence_fixed | 自门起点划分固定窗，统计不同SPAD | 共享一TDC，每周期可多次 | 达阈值窗口的末端；最后部分窗取门结束的左极限 |
| coincidence_sliding | 活跃SPAD脉冲数上穿阈值 | 共享一TDC，每周期可多次 | 达阈值的最新事件时刻 |
| analytic_reference | 周期开始全复位、首事件概率解析解 | 理想独立记录，不使用有限死时间 | 旧版本多项分布参考 |

## 统一物理和边界

事件引擎先产生泊松分布的信号和背景候选事件，再按SPAD分配并按时间排序。脉冲形状及SPAD抖动决定雪崩候选时间。SPAD使用非延长型死时间；被TDC或逻辑抛弃的雪崩仍然产生SPAD死时间。电子学抖动加在成功记录的时间戳上，然后落入TDC直方图bin。淬灭/恢复暂按阶跃恢复，不做模拟电路或器件载流子模型。

- SPAD死时间与TDC死时间独立且跨周期保留。每周期清空记录数量限制，但不清除正在恢复的器件状态。
- gated：SPAD仅在门内能雪崩；free_running：门外背景也能触发SPAD，影响门内可用性。两者均只允许门内逻辑事件进入TDC，不将其混称为全天候无门控TDC。
- 有门关闭间隔时，OR/符合逻辑在新门开始复位；门覆盖完整周期时OR和滑动窗状态连续保留。
- OR重叠脉冲合并成连续高电平，使用上升沿触发，宽度由or_pulse_width_ns控制。
- 符合检测统计不同SPAD，不把同一SPAD重复事件充作不同像素。滑动窗采用半开有效期，在到期瞬间不再活跃。
- 固定窗末端时间戳引入时间偏差，当前质心算法没有自动补偿该架构延迟；这应在专家审核/未来芯片标定中处理。不能把不同时间戳规则的误差直接归因于光学性能。
- 开头预热周期数、MC均值重复次数、事件资源上限集中在algorithms.yaml。预热是有限近似，可增加周期数检验长死时间下的收敛。

## 曲线、调试和资源

当前青色点/曲线已改为纯信号解析ground truth，不含读出损失；橙色为关闭激光后同模式的MC均值。含信号的实际读出MC均值仍在JSON中供诊断，不再绘成青色曲线。均值重复次数可配置，不可据少量MC估计极低虚警率。原始观测、重复统计、均值分别用独立随机流。详见histogram-display.md。

调试导出包含候选事件、死时间损失、门外雪崩、逻辑合并/拒绝、TDC容量损失，以及截取的触发时间记录。逐bin存活/首事件概率仍是理想解析参考，不能当成共享TDC/符合模式的真实概率。图上总采集损失估计包含逻辑与容量损失，并有MC采样误差。

资源限制在运行前按期望事件工作量检查，单次生成过程中也有实际事件上限。超限报错而非静默降级；可降低发数、重复次数或背景，或明确选择理想解析参考。低事件数但极高脉冲数也会受循环工作上限限制。

## 芯片映射的后续工作

暂不填写任何芯片型号对应关系。将来审核某芯片时记录：资料版本/页码、SPAD与TDC拓扑、是否OR脉冲合并、单次/多次、门控位置、死时间、仲裁策略、符合窗规则、时间戳位置、存储容量及模型差异。仅凭营销术语“binning”或“multi-event”不能建立映射。

本版不包含afterpulse、雪崩串扰、复杂FIFO带宽和厂商专用读出细节；这些是后续真实性扩展，而不是当前模式已经具备的能力。
