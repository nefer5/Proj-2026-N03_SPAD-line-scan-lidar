# 仿真评估路线：A → B → C

本规划替代最初按功能堆叠的版本路线。当前交付 A；B、C 只作设计规划，不提供假数据演示或已实现承诺。A版的下一轮优先级见 [项目审视](a-review.md)。

| 阶段 | 研究对象 | 光学输入 | 核心输出 | 状态 |
|---|---|---|---|---|
| A：单角通道 | 一个固定角通道的发射→目标→接收→SPAD→测距信号链 | 当前角通道Tx前能量、时间波形、入瞳面积、总效率、IFOV、滤光片 | 功率与滤光谱、光子预算、直方图、单通道测距统计、完整调试追踪 | 当前交付 |
| B：全光斑 | Tx全光斑经过Rx光学落到二维SPAD感光面的空间分布 | Tx H/V角能量分布、Rx各入射角收光效率及PSF数据库、像素几何、binning | 感光面能量图、角通道能量分配、各通道直方图、PSF空间串扰 | 规划 |
| C：结合扫描机制 | 光斑随转镜运动的时空采集 | B模型 + 扫描轨迹、机械角/光学角映射、PRF、帧率、同步及调度 | 脉冲级扫描采集、真实角bin累计数、距离线图/点云、运动与时序误差 | 规划 |

## A 当前闭环

输入单角通道脉冲能量，已经意味着外部确定了该角通道的能量份额；A 不根据线阵总能量或未知光学分布猜测份额。

- 时间脉冲支持高斯/矩形；能量与脉宽决定峰值，PRF决定平均光功率和累计时长。
- 入瞳支持圆形、椭圆、矩形；只计算几何面积，不求解光线、PSF或像差。
- 光谱支持基础/CSV/手动模式，太阳另有标准谱；图、透过率与背景积分共用数据，谱中心不自动随激光波长移动。
- SPAD已包含7种事件读出族及理想解析参考；有限死时间、共享TDC、多hit和符合逻辑见readout-modes.md。
- 评估视图和专家调试视图是 A 的两种观察方式，共用同一核心，并非 A/B 两套仿真。
- 历史独立串扰矩阵只保留在专家调试附加诊断中，不是B全光斑模型，也不改变A测距直方图。
- A已实现模型条件下的Pd/PFA检测判定与置信区间，见detection-performance.md；afterpulse、事件级雪崩串扰、标定漂移仍未实现。此类真实性增强可在A核心独立迭代，不等于实现B或C。

A验收：单位与能量参考面明确；滤光谱显示和积分一致；低/高通量概率守恒；门截断不补回能量；评估/调试数值一致；配置可保存并复现；网页发布不会混用新旧静态资源。

## B 计划与验收

1. 冻结Tx能量密度单位、H/V角度坐标和归一化约定。
2. 定义Rx效率参考面与PSF归一化，避免重复计入损耗。
3. 对角度/波长插值，合成二维感光面能量；先做像素级分配再按binning输出。
4. 将A信号链应用到各真实角通道，区分PSF串扰和器件雪崩串扰。

验收以能量守恒、插值基准、PSF截断/感光区边缘损失、单通道退化回A、多通道独立性为核心。文件接口草案保留在 model-design.md；实施前再确认实际光学数据格式。

## C 计划与验收

1. 定义转镜角随时间的函数及机械角到光学角的映射。
2. PRF生成脉冲时间，每发使用对应Tx/Rx角度和B模型。
3. 明确角bin边界、驻留、回扫时间、有效扫描比例和同步误差。
4. 输出实际每角bin累计数，避免无限增加脉冲数高估扫描性能。

均匀扫描且连续发射时，近似关系为：

$$
N_{\mathrm{pulse/bin}}\approx f_{\mathrm{PRF}}
\frac{\Delta\theta}{|\omega_{\mathrm{optical}}|}
$$

该式只是C规划中的驻留近似，当前A不会据此计算扫描性能。验收包含逐脉冲角度、重叠边界、回扫/盲区、帧率预算和静止扫描退化到B。

## 版本标识

按用户2026-09-15的阶段划分，当前A单通道基线定为V0.2（软件版本0.2.0）。原先B=V0.2、C=V0.3的编号规划作废：B/C仍为模型范围标签，具体发布版本待定。版本号不代表已完成全光斑或扫描机制。
