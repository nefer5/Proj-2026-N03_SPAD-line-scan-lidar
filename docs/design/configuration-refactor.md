# 配置重构第二阶段实施计划

授权：2026-10-18，用户要求整理文档后继续重构。当前进度唯一维护在[路标](../roadmap.md)，字段及默认归属规范唯一维护在[配置与用户数据](../guides/configuration-and-data.md)。本页保留实施顺序与验证门槛；该阶段已实现并完成自动自验，收录于0.6.15.dev0，证据见[第二阶段记录](../../artifacts/refactor-phase2-20261018-185756/README.md)。

1. 保存当前工作树、已解析配置/schema与固定数值场景，保留前端适配和“设为默认”功能。
2. 将defaults.yaml升级为领域分组结构：公共领域只定义一次，A的单角能量/IFOV与统计、SPAD直照、C曝光、预算硬件差异留在专用分组。共用扫描运动与系统目标使用同一来源。
3. 将默认组合和来源追踪集中到独立配置模块。A、SPAD、B、历史扫描、正式C与预算复用同一组合入口；正式C不再经过历史周期扫描的整份配置生成。旧YAML快照经显式版本适配读取，工况导入/导出协议不变。
4. “设为默认”使用同一来源映射，避免另写一套归属推断；继续提供预览、跨平台校验、指纹冲突保护、备份及原子写入。
5. 更新现行架构、配置指南与实施状态，保留旧HTML为有日期的历史快照。检查数值/schema对照、旧快照、非法配置、跨平台复用、默认写回及真实浏览器流程。

本阶段保持所有物理默认、算法策略、随机数协议、前端布局和公开工况schema不变。C列间复位、物理边界扩展、调度策略合并与界面语言统一另行实施，不以本阶段通过代替人工验收。

后续范围调整：用户明确C后续电学仍需迭代，电学扩展与C/预算调度整合暂缓，移出当前结构重构的完成标准，见[已确认决策](architecture-decisions.md#2026-10-18暂缓c电学仿真及输出调度整合)。
