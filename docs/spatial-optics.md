# B 全光斑空间光学：人工验收说明

状态：B正式平台已接入已确认的界面设计、模块化配置、双轴焦距、参数预览和重复采集统计。默认光学是可追溯的构造样例，不是实测系统。C实现与限制见 [扫描机制](scanning.md)。

## 使用入口

启动项目后访问 `/system`。`/spad` 是不依赖系统光学参数的独立研究台；`/` 和 `/debug` 继续提供 A 的兼容视图。

默认B/C阵列为H×V=2×16个读出通道：V表示16条线，H保留两路兼容维度。每通道沿用H/V空间合并设定，当前形成8×64个物理SPAD。原3×2历史工况不变；阵列数量变化不会自动扩大Tx/Rx光学覆盖。默认Tx是可分离二维高斯角分布，Rx是无色差高斯PSF；现在两者也可选择H/V独立阶数的超高斯。Rx宽度使用σ_H、σ_V，原单一σ仅作兼容迁移。模型与宽度定义见[双轴空间模型](spatial-profiles.md)。光学/器件共有默认值沿用初版A，包括1发累计、开启太阳和其他环境光。B默认含噪重复统计现为10次（包含首次观测），保留误差棒；噪声基线用解析标量，不额外执行关激光采集。B独立采集从完全恢复状态开始，不添加预热；同次采集内器件恢复连续。大角域下背景可能远高于单角通道A，资源超限时明确报错，不自动降低工况。

页面左侧按Tx、场景、Rx、SPAD、读出、环境光、采集统计分组。全折叠/展开只影响参数区；标题统一青色。参数预览由Python计算并显示配置指纹；历史采集结果保持原样。可折叠参数可视化覆盖Tx波形、滤光片、太阳辐照度、背景合成、PDE/FF、综合光谱响应、Tx角剖面、Rx映射、PSF剖面、采集时序。

建议人工复查：

1. 提交默认实验，查看探测面光子图、Tx角单元份额、PSF截获比例和各通道直方图。
2. 直方图支持通道编号/范围和二维点选，多通道使用分面。全门概览的橙色观察窗口可以拖动；每图旁可精确输入起止时间，所选通道同步缩放。观察窗口与物理接收门分开，不改变统计或寻峰范围。
3. 改变 PSF sigma、像面偏移、Tx角宽或中心，检查光斑、边缘损失和通道分配变化。
4. 在角度选择器中查看一个入射角单元落入各读出通道的份额。这是PSF空间映射，不是器件雪崩串扰矩阵。
5. 展开回波、太阳、其他环境光、候选/记录和能量守恒步骤，检查参考面、积分波段和单位。
6. 导出当前光学数据，再导入并选择 dataset 模型；相同光学数组和条件应得到相同采集记录。
7. 更换 SPAD/读出参数并重新运行。改变数字分箱可直接重放已有记录；改变硬件参数必须重新采集。

## 光学数据格式 v2与兼容迁移

第一版提供 JSON/YAML 离线数据适配。可用界面“导出当前光学数据”或 `data/synthetic/spatial-example.json` 作为完整样例，不需要手工填写巨型矩阵。

顶层必须包含 schema_version、coordinate_convention、label、synthetic、provenance、tx 和 rx。`synthetic` 必须如实说明数据是否为构造，实际配置与生成参数随结果保存。

新坐标约定为`optical_H_right_V_up__image_x_right_y_up`：H/x向右为正，V/y向上为正。角度为空气中光线方向的光学角，不是转镜机械角。角轴以mrad、波长以nm、像素边界以μm表示。v1的V/y向下数据经兼容层反转并取负对应坐标轴，同时重排数组，保留物理响应及能量并记录迁移说明；不重新归一化。

构造Rx的f_H与f_V分别控制两轴；新工况默认倒置，位置为对应焦距乘入射角正切的负值，再加像面偏移。共享公式本体和符号说明位于`formulas.yaml`、`formula-notes.yaml`的`b_rx_mapping_inverted`。`legacy_upright`只用于显式保留旧工况。数据库模式直接使用导入的PSF/效率，不套用构造焦距；预览显示其截获光质心，并注明有限阵列截断的影响。

| 数据项 | 形状与含义 |
|---|---|
| tx.h_edges_mrad / v_edges_mrad | Tx角单元边界，严格递增 |
| tx.energy_fraction | `[Nv,Nh]`，单元积分形状份额；实验中归一化到导入或构造Tx角域内，参考Tx光学之后；不是每sr密度 |
| rx.wavelength_nm / v_angle_mrad / h_angle_mrad | Rx数据库采样轴，严格递增 |
| rx.x_edges_um / y_edges_um | 实际完整像素边界，必须与当前阵列形状相符 |
| rx.collection_efficiency | `[Nw,Nv,Nh]`，从入瞳到无限像面的效率；不包含滤光、有限阵列截断、PDE或FF |
| rx.psf_pixel_fraction | `[Nw,Nv,Nh,Ny,Nx]`，无限归一化PSF在各完整像素中的积分份额 |

Tx单发能量定义于配置角域内、Tx光学之前。高斯和均匀构造分布在此域内归一化；导入Tx原始份额总和允许在(0,1]，实验显式归一化并在provenance.tx_energy_normalization保留原始总和。输入能量只乘一次Tx效率，不额外扣除角域外能量；全零Tx份额报错。每个Rx PSF的有限像素份额总和仍可小于1，缺失部分作为像面外损失，不重新归一化。非法负值、非有限数、超出1的效率/份额、轴顺序/数组形状错误明确报错；仅允许配置中的能量数值容差。

Rx使用角度和波长的线性插值，禁止外推。Tx采用文件中单元积分份额，在各单元中心查询Rx。Tx角域与构造Rx覆盖域独立配置，采样数也在算法配置中分别管理。旧完整B配置经legacy_config保留原来的耦合域。若模型组合的角度/波长覆盖不兼容，运行明确失败。

## 计算与审计范围

总Tx前能量乘Tx效率，再按角单元分配。场景采用同距离、同反射率的扩展朗伯目标；收光面积与大气双程损耗沿用 A 的定义。各角度经Rx效率、滤光和PSF落入像素后，统一进入SPAD核心。

背景按当前Tx角网格覆盖的场景角域积分，**不乘Tx能量份额**。这个有限场景域是显式假设，不能认为真实世界的域外背景必然为零。太阳与其他光沿用各自的 `spectral_inputs` 当前模式、源归一化和波段。背景原始光子数明确标注滤光片配置支持域的积分波段。

使用小角度立体角近似 `ΔH × ΔV`（rad²），范围受算法配置约束。高斯构造Rx不代表像差、衍射或色差分析；外部数据库可提供随角度和波长变化的效率/PSF。FF是像素内有效平均系数，未解析实际敏感区微几何。

所有能量损耗、各参考面光子、候选雪崩与最终混合记录分开输出。最终记录不能按来源期望比例线性拆分。完整结果包含光学数据、光谱积分节点/权重与像素光子数组、像素通道映射、TDC记录和配置快照。

直方图的蓝柱是首次采集；青色积分点和连续曲线是PDE/FF后、读出损失前的纯信号解析参考，复用A的函数；新B结果的橙线是每通道的理想噪声候选计数标量：PDE/FF后的光学背景加暗计数等噪声，按累计发数与标准时间分箱宽度缩放。它不计SPAD/TDC、首事件竞争、符合逻辑和容量损失，不是混合记录中的噪声分量或检测阈值。末尾不足整宽的时间分箱仍使用标准宽度的参考标量。历史结果的关激光输出均值保留原口径，不重算或改名。误差棒来自全部含噪重复采集的逐bin最小/最大值，含首次观测，不是置信区间。0次重复不生成误差棒。逐次直方图、种子、统计定义与算法限额均保存在结果中。

所选角单元的dB分布使用通道光学能量份额之比的10倍常用对数，参考通道可选。20倍对数只对应功率与幅度平方成正比时的幅度比。分子零显示负无穷，参考零显示未定义，导出分别使用`-inf`和`null`；不加epsilon或截断。高斯像素积分使用对称尾概率避免两个近1的CDF相减成为伪零。通道间比值矩阵是固定入射角下的条件响应比较，不代表逐个输入通道独立激励得到的完整传递矩阵，也不是SPAD雪崩串扰。

当前B输出每通道未经检测门限判定的距离估计，复用 A 的全门寻峰/质心算法。没有 B 专用 Pd/PFA 标定；也没有扫描、动态ROI、重叠分组、跨组共享TDC、afterpulse或雪崩串扰。不可把原始距离输出解释为已通过检测判据。

## 在像面上定位读出通道

第一节“模型原理与采集机制”提供“采集机制 · N 与 M”和“光学链路”两个标签页。说明依据可选择当前显示工况或当前参数预览；选择参数预览不会改变已保存任务。N是一次完整采集内的发射/曝光次数，M是独立重复完整实验的样本数；蓝柱取第1轮N发累积，误差棒比较M轮，不把M轮合成更大的蓝柱。页面用N=3、M=5的独立示例说明这两层循环。

结果直方图默认是“slot累积”：将本次所有gate的真实记录按相对各次Tx的ToF时间折叠。横轴只有一个门宽并不意味着仅统计一次曝光。切换“单gate”后，用保存的cycle编号筛选实际记录，绝不把slot计数除以N冒充单次观测。当前B未保存逐gate重复统计，因此该视图不提供误差棒；单发青色参考只描述本次Tx的理想信号，不描述其他曝光的迟到回波。

每个通道下方另有整个slot的逐gate记录数和门结束累计图，累计终点与该通道完整slot的记录数一致。发数很大时按算法策略将相邻gate精确合并为显示组，明确标注分组，既不丢gate也不降采样真实事件。CSV标明scope、gate_index、accumulated_shots和processing_bin_ps；“导出当前视图JSON”保留配置、原任务指纹、当前范围、时间轴、统计及绘图数组。

光子空间图可以在单发和N发slot光学期望总量之间切换，Python负责求和。这里积分的是各次发射对应的完整回波，尚未按接收门裁切，也未计PDE/FF及读出损失；不应把它当成slot接收门内的最终探测数。归一化Tx份额、PSF和dB比值不按N或M累加。记录数、损失和测距仍是首次完整采集的slot累计值。

B中slot显示口径对应本次N发序列，仿真长度为N个发射周期，最后一次门可以更早关闭；不能把它冒充另一个尚未配置的硬件T_slot上限。列间复位/DSP/MIPI在说明页中作为已讨论的工作机制显示，复位耗时与完整帧预算仍需在C接入。

正式 B 平台采集完成或载入历史任务后，在“通道分布与探测直方图”中输入通道号/范围并应用，或直接点选左侧列表、右侧像面通道。三者与下方直方图使用同一选择状态；点选只改变显示，不改变采集。至少保留一个通道，同时展示上限由算法配置的 `max_visible_channels` 提供。

示意图从左下角 H0/V0 开始编号，H 向右、V 向上，按 H 优先递增。编号公式和符号说明统一引用 `b_readout_channel_index`。细网格表示完整物理 SPAD 像素，粗框表示读出分组；图形采用实际 Rx 像素边界并保持等比例，适用于非均匀像素坐标。悬停或键盘聚焦可看通道坐标范围、SPAD 数、入射光子数和最终记录数；Enter 或空格可选择通道。

半透明底图是该次采集工况整束信号光在探测面各完整像素的积分，参考面位于 PDE/FF 前，色标单位为光子/物理像素/发。它不表示单角 PSF、背景光或最终探测计数。通道详情中的光子数按真实像素分组求和；FF 仍是器件响应系数，图上不构造像素内敏感区形状。底图、不透明度和细网格开关均只影响绘制。

参数侧汇总对应当前草稿的已校验 Python 预览；结果侧示意图始终对应其标注的任务与配置指纹。修改草稿后，已有采集结果不跟着改；提交并完成新采集后，结果布局、光斑和直方图一起更新。重放时间分箱保留原空间布局。旧任务缺少的显示元数据在读取时补齐，不重采样或改写原文件。
