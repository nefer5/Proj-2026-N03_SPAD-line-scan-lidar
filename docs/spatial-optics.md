# B 全光斑空间光学：人工验收说明

状态：实现及自动验收完成后交人工验收。默认数据是可追溯的构造样例，不是任何实测光学系统。C 扫描尚未实现。

## 使用入口

启动项目后访问 `/system`。`/spad` 是不依赖系统光学参数的独立研究台；`/` 和 `/debug` 继续提供 A 的兼容视图。

默认 B 样例为 3×2 个读出通道，每通道沿用 H/V 设定；默认形成 12×8 个完整物理像素。Tx 是可分离二维高斯角分布，Rx 是无色差高斯 PSF，按像素边界进行高斯积分。默认关闭太阳和其他环境光，以便先查看信号映射；可显式启用并检查事件工作量。

建议人工复查：

1. 提交默认实验，查看探测面光子图、Tx角单元份额、PSF截获比例和各通道直方图。
2. 将图形时间范围设在预期回波附近；缩放只影响显示，不改变统计。
3. 改变 PSF sigma、像面偏移、Tx角宽或中心，检查光斑、边缘损失和通道分配变化。
4. 在角度选择器中查看一个入射角单元落入各读出通道的份额。这是PSF空间映射，不是器件雪崩串扰矩阵。
5. 展开回波、太阳、其他环境光、候选/记录和能量守恒步骤，检查参考面、积分波段和单位。
6. 导出当前光学数据，再导入并选择 dataset 模型；相同光学数组和条件应得到相同采集记录。
7. 更换 SPAD/读出参数并重新运行。改变数字分箱可直接重放已有记录；改变硬件参数必须重新采集。

## 光学数据格式 v1

第一版提供 JSON/YAML 离线数据适配。可用界面“导出当前光学数据”或 `data/synthetic/spatial-example.json` 作为完整样例，不需要手工填写巨型矩阵。

顶层必须包含 schema_version、coordinate_convention、label、synthetic、provenance、tx 和 rx。`synthetic` 必须如实说明数据是否为构造，实际配置与生成参数随结果保存。

坐标约定为 `optical_H_right_V_down__image_x_right_y_down`：H向右、V向下，对应像面x向右、y向下。角度为空气中光线方向的光学角，不是转镜机械角。角轴以mrad、波长以nm、像素边界以μm表示。

| 数据项 | 形状与含义 |
|---|---|
| tx.h_edges_mrad / v_edges_mrad | Tx角单元边界，严格递增 |
| tx.energy_fraction | `[Nv,Nh]`，单元能量份额，参考Tx光学之后的整个光束；不是每sr密度 |
| rx.wavelength_nm / v_angle_mrad / h_angle_mrad | Rx数据库采样轴，严格递增 |
| rx.x_edges_um / y_edges_um | 实际完整像素边界，必须与当前阵列形状相符 |
| rx.collection_efficiency | `[Nw,Nv,Nh]`，从入瞳到无限像面的效率；不包含滤光、有限阵列截断、PDE或FF |
| rx.psf_pixel_fraction | `[Nw,Nv,Nh,Ny,Nx]`，无限归一化PSF在各完整像素中的积分份额 |

Tx份额总和可以小于1，缺失部分作为角域截断损失。每个PSF的有限像素份额总和也可以小于1，缺失部分作为像面外损失。均不重新归一化。非法负值、非有限数、超出1的效率/份额、轴顺序/数组形状错误明确报错；仅允许配置中的能量数值容差。

Rx使用角度和波长的线性插值，禁止外推。Tx采用文件中单元积分份额，在各单元中心查询Rx。Tx和Rx模型可独立选择；若组合后的角度/波长覆盖不兼容，运行明确失败。

## 计算与审计范围

总Tx前能量乘Tx效率，再按角单元分配。场景采用同距离、同反射率的扩展朗伯目标；收光面积与大气双程损耗沿用 A 的定义。各角度经Rx效率、滤光和PSF落入像素后，统一进入SPAD核心。

背景按当前Tx角网格覆盖的场景角域积分，**不乘Tx能量份额**。这个有限场景域是显式假设，不能认为真实世界的域外背景必然为零。太阳与其他光沿用各自的 `spectral_inputs` 当前模式、源归一化和波段。背景原始光子数明确标注滤光片配置支持域的积分波段。

使用小角度立体角近似 `ΔH × ΔV`（rad²），范围受算法配置约束。高斯构造Rx不代表像差、衍射或色差分析；外部数据库可提供随角度和波长变化的效率/PSF。FF是像素内有效平均系数，未解析实际敏感区微几何。

所有能量损耗、各参考面光子、候选雪崩与最终混合记录分开输出。最终记录不能按来源期望比例线性拆分。完整结果包含光学数据、光谱积分节点/权重与像素光子数组、像素通道映射、TDC记录和配置快照。

当前B输出每通道未经检测门限判定的距离估计，复用 A 的全门寻峰/质心算法。没有 B 专用 Pd/PFA 标定；也没有扫描、动态ROI、重叠分组、跨组共享TDC、afterpulse或雪崩串扰。不可把原始距离输出解释为已通过检测判据。

## 验收证据

`tests/test_spatial_optics.py` 覆盖守恒、边缘损失、零PDE、三维插值基准、导入往返、多通道独立性、背景与Tx无关，以及均匀单通道退化到 A 的所有光子参考面和候选期望。

`artifacts/architecture-upgrade/stage-3/` 保存默认配置、完整结果、最终测试日志与实际网页截图。对应构造数据可直接替换为符合此契约的实际数据，随后重新验收。
