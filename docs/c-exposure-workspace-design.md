# C 线扫曝光与资源规划工作台：设计待审核

本轮提供设计说明与独立界面预览。按用户单独授权，将 B/C 阵列默认值从 H×V=3×2 改为 2×16；正式 `/system/scan` 的新界面、列调度和计算模型仍待审核后实现。

## 架构约定

用户明确：本项目聚焦线扫LiDAR。一个slot对应点云的一列，SPAD为线阵；列内各行同时采集、处理和读出。一列可使用多次发射。这里的带宽主要指数据读出/传输带宽。

slot应命名为**列采集时隙**，用Sₖ或“第k列”标识。当前程序把一次名义激光周期叫slot，后续应改称**触发周期**。不能只改标签就把两者混为一谈。

用户进一步指定默认H×V为2×16：V=16表达线数，H=2保留兼容维度。主视图按16行和H路选择展示，不称为32线。当前核心按32个读出通道计算，单路显示不等于另一H路已在硬件中关闭；未来H启用掩码/双路合并策略仍需明确。H/V空间合并沿用已有默认值，不能另设一份SPAD总数。

旧3×2样例只用于解释截图，不充当新线阵的预测结果。整列并行处理，不画成逐行轮流曝光。整列锁存后如何通过链路输出，取决于实际接口和缓冲架构。修改阵列规模不会自动扩大Tx/Rx角域或照亮全部16行；光学覆盖须另行核对。

## 术语表

| 名称 | 标识/单位 | 定义 |
|---|---|---|
| 点云帧 | Fₘ、Hz | 一次完整扫描输出；含多列和多行 |
| 列采集时隙 slot | Sₖ、μs/ns | 生成一列数据的时间安排；线阵各行并行，可含多次发射 |
| 触发周期/脉冲间隔 | Pᵢ、ns/μs | 相邻名义触发之间的间隔；单次触发未必启用发射 |
| 扫描角格 | Aⱼ、mrad/° | 用来标记/重建方向的角区间；不叫裸bin |
| TCSPC时间分箱 | Tᵦ、ps/ns | 到达时间直方图的量化区间；原点由明确的触发/记录时钟规定 |
| SPAD空间合并 | H×V、个 | 多个物理SPAD组成一个读出组；与扫描角格不同 |
| 光学积分角单元 | 数值网格、mrad | B光斑积分与PSF查询的计算单元；不代表点云输出分辨率 |

slot与输出列一一对应。扫描角格是空间标签/重建网格。匀速、均匀规划时可将一列关联一个角格；非匀速扫描、编码器误差或重采样时不应强制把两者等同。原始数据同时保留采集列ID、编码器角标签和仿真真值标签。

## 截图的真实含义

截图来自保存的两帧快速示例。单帧1ms，前扫0.8ms、回扫0.2ms；光学主轴从−20扫到+20mrad，20个扫描角格、每格2mrad。每10μs一个触发，前扫启用80发，因此当前匀速样例每角格4发。

“bin 7 · −5mrad”应改为“A07角格｜中心−5mrad｜范围[−6,−4)mrad”。编号从0开始，因此它是第8个角格。卡片的7是角格编号、4是归档发射次数、−5是角中心；不是时间分箱、距离或SPAD编号。发数图的3.92～4.08来自原图自动缩放，数据实际均为整数4；新版从0展示整数发数。

左图是扫描轴方向随参考时间的变化，不是激光脉冲波形。三条曲线分别是控制计划、实际发射时刻的Tx光学轴、编码器标签；此样例无相关误差，曲线重合。回扫时光学轴继续运动，但激光关闭。

旧“分配bin”改称**编码器归属角格**：根据编码器时间/角度标签归档，用于实际记录重建。旧“真实bin”改称**实际发射方向角格（仅仿真审计）**：按实际发射时刻的Tx主轴方向计算，既不是回波到达时的Rx姿态，也不是单个光子/目标的真实空间位置。两个计数还分别采用参考帧与真实发射帧及前回扫有效性，时序误差可能使计数不同；不能用真值标签替换测量标签。

## 两个研究工作区

### 曝光策略与跨列影响

- 固定波形、单发能量、发数、场景和器件参数，对比列内均匀发射、成组突发、非均匀间隔、门控平移、多窄门/宽门等策略。
- 分开描述Tx光源拖尾、场景多径/不同距离的晚到回波、接收电子响应尾迹、SPAD恢复、TDC忙碌/容量；这些不是一种“拖尾”。
- 场景支持按线阵行定义距离，也区分单行多回波。近远回波可越过下次触发甚至列边界。
- 一个连续时间引擎处理全部slot；切换列/帧不隐式重置SPAD或TDC。复用同一SPAD核心，改的是外层入射事件、门控和调度。
- 显示观测、理想参考、背景、重复统计和明确的损失原因。比较条件与随机种子可追溯；未计算的图层不伪造。

### 时间资源与数据带宽规划

- 帧周期、有效扫描时间、回扫/稳定/保护时间、列数与列时长；均匀规划可显示参考关系，但非均匀时按实际时隙逐项核对。
- 水平扫描FOV/列角步距、垂直线阵FOV/行标定、输出点数、光学分辨能力、TDC时间量化分别命名；点云采样数不等于光学分辨率，时间分箱对应距离格宽不等于测距精度。
- 数据路径按整列处理/锁存、内部读出、列缓冲、输出链路分层。输出模式区分点云、多回波、直方图和原始时间戳。
- 线阵行数已指定为16；参与输出的H路、每点字段位宽、每行回波数、列/帧头、协议开销、净链路速率、缓冲容量和并行规则仍须有定义，缺失时显示待定义，不填0。
- 分别报告平均数据率、列突发峰值、读出/传输完成期限、缓冲峰值与积压。不能只用平均带宽判定可行。
- 发射、飞行、接收门、恢复和数据输出可能重叠。可行性检查应基于时间区间、资源占用和依赖关系，不能一律相加，也不能把关门段都当成可自由使用的余量。

## 多尺度时序与流水线

1. 全帧：扫描/回扫、列Sₖ、发射分布和整体资源安排。
2. 两个相邻列：列边界、触发Pᵢ、实际发射、回波到达、SPAD器件门、TDC记录门、跨列影响。
3. 单触发/纳秒放大：真实Tx波形、到达波形、选定行/物理SPAD的雪崩与恢复、TDC接受/拒绝。
4. 整列输出流水线：列锁存→列内并行处理→缓冲→链路输出；单/双缓冲与是否允许跨列重叠需要显式声明。

图旁同时有缩放/拖动、精确起止时间、选列/选脉冲/选行控件。多个量级不能硬塞进一张图；微秒总览的竖线表示发射事件，不用线宽冒充2ns脉宽。

SPAD恢复是每颗器件的状态，不能把整条线阵画成同时进入一个死时间。现存量化TDC记录不足以还原精确雪崩时刻和所有拒绝事件；后续需从同一核心导出所选时窗的真实事件轨迹，不从量化记录倒造内部状态。

## 预览数据边界

数值基准通过当前 YAML 默认工况和现有 Python 调度、公共曲线函数生成；相邻角格 A07/A08 各4发的匀速片段用于演示两个列级 slot，时间分别为280–320μs、320–360μs。该映射仅是本例的对齐方式。

新曝光策略、可控拖尾、读出耗时和带宽队列均以明确标注的概念示意/空态呈现，不声称已计算。预览不调用生产任务提交接口；编辑草案不会回写正式默认配置。当前正式模型的周期发射、Gaussian/rectangular波形和已有径向场景不足以完整覆盖上述新研究项。

审核重点：术语与列级slot、两个研究入口、时序层级、门控/读出边界、缺失硬件约束的呈现方式。审核后再实现可配置调度与数据模型。

## 第二轮补充：镜面运动、逐发列表与 DSP / MIPI

用户已确认采用双缓冲：采集下一列时允许处理或搬运上一列。MIPI 位于 DSP 后，将处理结果输出到主机。预览保留串行关系作为对照，但正式设计主路径为整列采集、锁存、DSP、输出缓冲、MIPI、主机；不再将 MIPI 方向当成未知。

### 转镜与光学角度

- 将机械角速度与 Tx 光学扫描角速度分开。当前机械角范围、帧率、轨迹和光学角倍率共同决定两者；摆扫帧率不等同连续转镜 RPM。若后续采用匀速多面转镜，要另行定义 RPM、棱面数、有效面段和标定映射，并校验帧率/FOV约束。
- 每个 slot 展示全部实际发射时刻、与前一发的间隔、机械角、Tx世界方向、相邻发射角差。区分整个 slot 扫过的角度与首发至末发的角度。
- 每发、每个局部光学角单元的世界方向在发射时刻确定；按场景传播得到返回时刻，再查询该时刻 Rx 主轴。Rx 相对入射角定义为发射射线的世界角减去返回时刻的 Rx 主轴角。Rx静态失配、飞行中扫描和编码器归档误差分开呈现。
- 飞行中 Rx 转角是返回与发射时刻的 Rx 主轴差；它和相对入射角仅在特定共轴/同速设置下互为相反数。电子标定延迟不能用于计算转镜继续转动的光程时间。
- 空间映射继续使用 B 公共 `image_center`，保持倒置和 H/V 独立焦距。固定PSF仅固定局部响应形状，不固定光斑中心或每通道截获能量；完整损失评估仍须通过B的PSF积分，再进入同一SPAD核心。
- 当前数值预览只用已有 `mirror_pose`、`reflection_range`、`image_center` 对主轴中心射线（局部 H=V=0）做诊断。距离采样复用 `algorithms.performance_sweep_range_values`，附加当前场景距离；不在前端创建新的角度/飞行时间算法。
- 非匀速或跨转向点直接查询两时刻姿态，不套用恒定角速度近似。现有核心以回波中心采样Rx姿态，脉冲内部的扫描拖影尚未展开，应保留为后续模型边界。

当前参考：机械角速度25 rad/s，光学角速度50 rad/s；10 μs发射间隔对应0.5 mrad，40 μs列slot扫过2 mrad，4发首末相差1.5 mrad。100 m目标飞行约667.128 ns，Rx转过+0.0333564 mrad，相对入射角为−0.0333564 mrad；当前倒置映射的运动像移为+0.667128 μm。数值均由Python生成，不作为额外默认值。

### slot 内逐发计划

拟定 `tx.pulse_plan` 为行列表，每行包含 `time_offset_ns` 和 `energy_nj`：前者是相对列slot起点的波形中心时间，后者为Tx光学前的全光斑单发能量。既有波形形状与宽度作为继承项，将来需要逐发波形时使用显式引用。当前预览提供表格增删、直接JSON输入和紫色时序泳道，列表作为每列重复的模板。

时间必须有限、严格递增、落在列slot半开区间内；能量为非负有限数，零能量表示暗触发，空列表表示该列不打光。未知键、重复时刻、逆序和越界明确报错，不排序、裁剪或悄悄合并。首末脉冲的尾部或回波可跨越列边界；SPAD状态不能随列表边界重置。

列表在正式实现时应成为显式模式下逐发时序与能量的唯一来源；原周期PRF/统一能量只在周期生成模式生效。不得同时让两份配置控制同一发。导入时必须明确模式并通过类型约束校验。时序对照实验可以锁定能量；用户也可以同时改变时序与逐发能量，此时不得声称比较条件只有时序不同。

预览编辑只画输入事件；其他回波/角度数值仍是Python基准，泳道和提示明确分开。新逐发能量尚未送入生产仿真。

### DSP 和 MIPI 泳道

两个slot时序增加DSP和MIPI独立泳道，块上的Sₖ指被处理的数据列，不是当前横轴所属列。前一列的DSP/MIPI允许与后一列采集重叠。预览提供每列的DSP起点/耗时、MIPI起点/耗时；起点均相对被处理列开始，四项初始留空，空白不代表零。

当前审核交互按用户输入位置直接绘图；约定DSP在列末锁存后开始，MIPI在本列DSP结束后输出，不自动挪动区间。两列图可看到来自前一列的处理块。明确区分用户给定的时间示意和未来由依赖、队列与资源求解的时间结果。

正式实现需要明确：DSP整列延迟与启动间隔、DSP并发度、缓存归属/释放点、MIPI净吞吐与协议开销、结果格式、DMA与MIPI关系、背压/丢列策略。双缓冲不保证无积压；不得在缺少这些参数时输出带宽可行或帧率达标的结论。后续除平均/峰值带宽，还要显示DSP/MIPI完成期限、空闲/等待、缓冲占用和跨帧积压。
