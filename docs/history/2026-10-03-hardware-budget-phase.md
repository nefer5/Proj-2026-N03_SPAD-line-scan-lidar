## 当前表单冻结

完整输入在[阶段证据](../../artifacts/budget-closeout-2026-10-03/README.md)。唯一运行默认仍是config/defaults.yaml；budget专用覆盖采用必要差异，A、独立SPAD、B、C基础默认保持不变。Tx/Rx派生角边界及距离参考的算法采样范围不重复写为第二份默认。

| 项目 | 本次冻结工况 |
|---|---|
| 系统目标 | HFOV 120°、VFOV 20°、192线、1000 slot/帧、10 Hz、扫描利用率0.667 |
| 发射 | 全Tx角域等效平均功率1000 W，Tx光学前；905 nm、矩形脉冲2 ns、Tx效率1、H全宽3 mrad；每slot 12发 |
| Rx与像素 | 单通道Rx H全宽3.5 mrad，V留空跟随Tx；H8×V4 binning，pitch 10 μm，PSF H/V标准差4 μm |
| Hist窗口 | gate 2048 ns，bin 1 ns，即2048 bins；计数字宽16 bit/bin |
| 输出 | Echo：最多6回波/点、每回波8 bins、描述字段8 B；Range记录16 B/点作为可切换格式设置保留 |
| 拓扑 | 一颗192线chip、一个MIPI link、4条data lane，每lane 1.5 Gbit/s；物理发送利用率0.8 |
| 处理 | 固定A采集/B处理、接收包络结束交接；搬移6.291456 μs、清零1 μs、输入延迟1 μs、DSP 27 μs、打包1 μs |
| 协议 | 应用chip头16 B，CSI-2最大payload 4096 B，未加LS/LE，逐长包附加间隔0；FS/FE按模型计入 |

公共核心计算的当前Echo预算：每slot应用数据27,664 B，链路字节27,706 B，基础D-PHY发送46.18 μs；有效速率4.8 Gbit/s，10 Hz平均链路需求2.22 Gbit/s。每bank逻辑SRAM需求768 KiB，双bank共1.50 MiB，有限两列FIFO需求54.03 KiB。观察的连续帧调度无slot延后、无FIFO等待、无拖尾增长。

这些是所输入资源能力下的结果。当前6.291456 μs搬移786,432 B，反算chip内搬移要求为1,000,000 Mbit/s；此输入被原样保留，并未认定现实硬件能够实现。SRAM未计DSP额外工作区、对齐或ECC；有限帧观察不是长期稳定证明。
