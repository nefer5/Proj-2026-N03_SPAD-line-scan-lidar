# Sony相关参数的工程参考

按用户已查验的截图设置，作为IMX459相关技术的数量级参考，不以复现完整芯片为目标。截图来源名称为《SPAD depth sensor for automotive LiDAR systems》。本次不继续进行数据来源核查。

| 截图指标 | 当前配置键 | 工程参考值 | 条件及处理 |
| --- | --- | --- | --- |
| DCR | `dcr_cps_per_spad` | 2007 cps/SPAD | 约2 kcps，截图注明60°C；当前作为固定泊松候选率，不做温度换算 |
| 时间抖动FWHM | `spad_jitter_fwhm_ps` | 173 ps | 室温、Vex=3V；当前高斯近似 |
| 时间抖动FW10% | 无独立输入 | 320 ps | 仅记录参考，不作为FWHM，不额外叠加一次抖动 |
| SPAD死时间 | `spad_dead_time_ns` | 6 ns | 事件模式下非延长型、阶跃恢复；解析参考模式不使用 |
| TDC时间分辨率 | `tdc_bin_ps` | 1000 ps | 时间量化bin；当前本地已为此值，保持不变 |

高斯近似由FWHM唯一确定形状，173ps对应标准差约73.5ps，FW10%约315ps。与320ps参考接近，但只凭两个宽度不能恢复真实响应曲线的偏斜或尾部。

仅修改上述可对应项。TDC死时间仍单独配置，不能把SPAD的6ns或TDC的1000ps代入它。其他电子抖动、门控、读出模式、binning、FF及PDE谱均保留原设置。

因此当前是混合工程参考：DCR与抖动来自不同测试条件，PDE仍为此前选定的Van Sieleghem文献曲线及其外插段，FF仍由用户指定。不会将用户所选读出模式自动称为IMX459拓扑，也未引入温度/过压联动模型。后续按用户要求将运行默认读出改为`independent_multi`、累计1发；这不改变上述器件参考条件。

运行默认值唯一维护在 `config/defaults.yaml`；本表仅记录本次选择，后续用户修改配置时以本次仿真导出的配置快照为准。
