# 统一光谱输入：先选模式，再输入

适用于滤光片、其他环境光、PDE及太阳光。光谱模式与SPAD读出模式是两个独立概念；本轮不改变读出架构。

## 输入模式

| 模式 | 显示的输入 | 实际计算来源 |
|---|---|---|
| 基础类型 | 理想波形选择、幅值、有效波段及该波形特征量 | Python基础波形函数 |
| CSV文件导入 | 文件选择、文件名与只读数据预览、插值选择 | csv_points按PCHIP/线性插值 |
| 手动输入 | 多行编辑区、应用按钮、插值选择 | 已应用的manual_points按PCHIP/线性插值 |
| 标准太阳谱（仅太阳光） | 标准名称，太阳照度lux仍在外部设置 | 现有ASTM G173-03 AM1.5G参考数据 |

每次只显示一个模式的输入区。CSV和手动数据分别保存，切换不覆盖另一组数据；手动草稿只有在手动模式激活时才阻止仿真。CSV模式没有数据时必须先导入，不能静默使用基础或手动曲线。导出保存所有模式的数据和最后通过验证的基础参数；不把未应用/无效草稿作为可复现配置。

CSV首列为wavelength_nm，第二列按对象为transmission、radiance、pde或irradiance，也接受通用value。手动输入可无表头，逗号、空格和Tab均支持。采样点至少两点，波长严格递增；无自动排序、去重或裁剪。采样范围外为0。

## 基础波形特征量

| 类型 | 特征量 | 定义 |
|---|---|---|
| 常量 | 幅值、有效波段起止 | 仅在指定波段内恒定，波段外为0 |
| 矩形 | 幅值、中心波长、全宽、有效波段 | 中心两侧各延伸半个全宽，再被有效波段截断 |
| 高斯 | 峰值、中心波长、FWHM、有效波段 | 中心值等于峰值，中心左右半个FWHM处为半峰值；波段可截断尾部 |
| cosine平顶 | 峰值、中心波长、平顶全宽、单侧过渡宽度、有效波段 | 中央平顶，两侧按半个余弦周期从峰值平滑降至0；总支撑宽度=平顶全宽+2×单侧过渡宽度 |

单侧过渡宽度为0时，cosine平顶退化为矩形；平顶宽度为0且过渡宽度正数时形成升余弦峰。有效波段外一律为0，不会为补偿截断而重新归一化。中心波长独立于激光波长，修改激光波长不会自动平移滤光片。

公式源码为config/formulas.yaml中的basic_constant、basic_rectangle、basic_gaussian、basic_cosine_flat，界面通过本地KaTeX渲染。Python的curves.py执行数值计算；前端不计算这些物理波形。

## 幅值与单位

- 滤光片：透过率0–1。
- PDE：感光区探测概率0–1，不含FF。
- 其他环境光：W/(m²·sr·nm)，再乘独立强度倍率。
- 太阳自定义谱：归一化前的相对谱值；强度仍由目标面lux决定。整体乘一个正幅值会被lux归一化抵消，只改变归一化前的参考量。

正lux要求所选太阳谱含有非零明视觉光谱成分；纯近红外且有效波段不覆盖可见光的谱形不能由正lux确定辐射强度，会清晰报错。关闭太阳光或lux=0时不要求此归一化。

## 配置及兼容

defaults.yaml新增统一的spectral_inputs，其下为filter、other、pde、solar。每组包含mode、basic、interpolation、csv_points、manual_points、csv_name。basic的字段名及说明统一维护于curve-inputs.yaml。

旧filter_curve、pde_mode、other_light_mode等字段仅在导入兼容层处理，输出中不再保留。旧采样点迁入手动模式；旧常量PDE/其他背景迁入基础常量；旧矩形滤光片迁入基础矩形。同一对象不能同时传旧字段和新spectral_inputs字段，避免两套配置竞争。

不含上述旧字段的其他工况保持不变；旧常量模型导入后的有效波段使用新默认波段，若原工况波长超出该范围，请检查并扩展有效波段。配置含明确有限波段是本轮新增的物理约定。

## 计算与验收

作图、激光波长处求值及背景联合积分共用Curve。矩形边界、cosine平顶边界和过渡段、高斯局部区域均加入积分网格，不依赖画图采样密度。基础波形的单谱积分使用闭式公式；多谱乘积使用分段Gauss求积。纯分段多项式的乘积保持原精度，高斯/余弦则通过局部网格细分获得数值精度，并与独立积分对照。

基础曲线不显示伪造的原始散点；CSV/手动曲线保留原始散点。太阳自定义采样点在图中随lux归一化共同缩放。框架仍属于A单角通道版本。
