# H/V空间binning与通道SPAD数

输入改为两个正整数H_binning、V_binning；N_SPAD由两者乘积派生，不再单独设置或写入配置。默认4×4=16。

- H_binning：水平方向聚合数；V_binning：垂直方向聚合数。
- 派生总数统一影响DCR、其他逐SPAD电子噪声、光学事件的均匀分配、独立读出TDC数量和符合阈值校验。
- 总数上限仍使用algorithms.yaml的max_spads_per_channel，校验的是H×V。
- A版在相同总数时，4×4和8×2产生相同统计模型；尚未模拟像素间距、二维PSF、空间非均匀照明或不同排布的串扰。
- 通道IFOV独立输入，不因H/V自动扩大；如真实硬件扩大binning会扩大接收视场，用户须同步填写整个通道的IFOV。B版再建立明确空间映射。

旧配置只有spads_per_channel时，无法推断二维排布，因此按H=旧总数、V=1迁移，保留计数行为并要求用户确认布局。禁止同时提供旧总数和H/V，避免歧义。新YAML只保存H/V；Python内部spads_per_channel为只读派生属性。

相关公式与当前数值同时显示在SPAD输入区和光子预算共同条件中。公式源码为formulas.yaml的binning，变量说明为formula-notes.yaml的同名项。

## 滤光片波段和加权带宽

当前滤光片有效范围为855–955nm（100nm），中心905nm、矩形全宽10nm、默认峰值透过率0.95。实际非零通带为900–910nm，加权带宽是透过率曲线面积，因此为9.5nm。它等效于一个透过率100%、宽9.5nm的矩形对平坦谱的积分贡献；不是说实际通带变成9.5nm，也不是通用光谱下只用带宽就能替代联合积分。

扩大有效范围会改变预算表中进入Rx的带内原始光子数；只要未截断非零通带，探测面光功率和候选计数不因此改变。

## PDE与太阳谱中心的联动建议

PDE和太阳谱不应自动平移到激光波长。当前PDE手动模式使用采样点，905nm处PDE为18%；太阳standard模式使用标准谱，强度按lux归一化。基础模式中PDE中心700nm、太阳中心550nm仅是备用值，常量类型甚至不使用中心参数。

界面应联动显示当前生效模式和激光处实际值；只有用户选择基础矩形/高斯/cosine平顶时，才使用该模式的中心参数。修改激光波长只是改变查询位置，不应修改原始谱线。
