# 太阳光、其他环境光与PDE光谱

## 来源与定义

太阳光使用 [NLR官方ASTM G173-03参考数据](https://www.nlr.gov/grid/solar-resource/spectra-am1.5) 的AM1.5 Global Tilt列。该谱形对应规定的大气条件和37°参考面；本模拟固定其形状，仅缩放幅度。不是根据当地时间、天气或目标倾角预测实际太阳谱，也不是太阳盘直视模型。

lux归一化使用 [CIE 2019明视觉V(lambda)](https://doi.org/10.25039/CIE.DS.dktna2s3) 和683lm/W。标准表积分约1000.370656 W/m²，按本项目分段线性积分对应109494.736 lux。因此输入50000 lux时为约456.812 W/m²。改变光谱形状后该比例一般不成立。

太阳lux定义为目标面照度。反射到接收方向的谱辐亮度由太阳谱辐照度乘solar_reflectivity/π得到，假设灰朗伯面。solar_reflectivity独立于激光目标反射率设置，两者相同时应由用户同步配置。太阳到目标的标准大气影响已在谱形内；不再乘激光双程大气系数。目标到接收机的额外背景路径衰减暂忽略。

其他环境光输入直接是接收方向的谱辐亮度，单位W/(m²·sr·nm)，不做lux转换，也不再乘反射率。默认数据为人工示例；支持手动编辑或CSV导入，PCHIP/线性插值，采样范围外为0。constant模式保留旧版平坦背景参数。

PDE为感光区探测概率，0–1。示例仅模拟硅SPAD大致谱形，不属于任何具体器件规格。信号用激光波长处PDE，背景用完整PDE谱积分；fill factor独立乘一次，若输入是已含FF的整像素PDE应将FF设为1。constant模式保留原标量pde。

## 联合积分

标准光谱和CIE数据按线性插值。用户其他光/PDE/滤光片按选择的插值方法。所有曲线结点的并集划分积分区间，默认6点Gauss-Legendre求积：分段三次谱、滤光片、PDE及波长因子的乘积最高10次，6点求积在这些分段上精确到浮点误差。没有依赖绘图点密度估算背景。

计算顺序为：谱辐亮度 → 乘滤光片 → 乘波长对应的光子换算因子及PDE → 谱积分 → 乘入瞳面积、通道立体角、Rx效率、门宽和FF。太阳与其他光分别积分，最后相加。DCR与其他电子随机噪声不经过PDE或FF。

公式展示源码集中在config/formulas.yaml（spectral），由专家页的本地KaTeX渲染；实际计算源为spectra.py和simulator.py。调试JSON提供积分结点/权重、分光源谱值、滤光片和PDE值以及标准数据SHA256，供复核。

## 数据与界面

- defaults.yaml：太阳开关、目标面lux、灰反射率；其他环境光开关/倍率/采样点；PDE模式/采样点。
- spectral-data.yaml：标准数据来源、列约定与校验和；原始文件与许可见data/reference/README.md。
- examples/other-light-example.csv：wavelength_nm,radiance，两列示例谱辐亮度。
- examples/pde-example.csv：wavelength_nm,pde，两列示例感光区PDE。
- 太阳图纵轴为谱辐照度；合成背景图统一为接收方向谱辐亮度；PDE图为概率。不可将不同单位的曲线直接相加。

曲线窗口主要展示SPAD关注波段；太阳总辐照度和lux仍按标准数据完整波段积分。运行只读取本地数据，不依赖网络。标准数据首次加载会校验哈希并缓存，修改标准文件须同步验证元数据并重启服务；用户可编辑的工况和光谱仍按每次请求加载。
