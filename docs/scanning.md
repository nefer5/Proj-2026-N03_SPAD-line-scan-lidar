# C 扫描机制：实现、数据口径与整体验收

状态：C 已实现；A/B/C 共用 SPAD 器件与读出核心。整套结果等待用户最终验收。默认扫描/场景参数与光学样例均是明确构造的研究工况，不代表具体转镜、整机或目标的实测性能。

## 入口与复用

- `/spad`：直接照明下独立研究 SPAD。
- `/system`：B 静态全光斑。
- `/system/scan`：C 逐脉冲扫描。
- B页面“转到扫描C”将已验证的器件、光学、读出、时序和seed转入C。扫描设置从唯一默认值源建立；不继承B的独立累计发数。

新增代码主要在 `scan/`、`scene/scan_target.py`、`experiments/scanning.py` 和 `processing/scan_reconstruction.py`。Tx传输、场景朗伯传播、Rx插值/像素积分、SPAD光子转换、器件恢复、读出、电子时间误差及量化均调用公共模块。

## 时序和扫描轨迹

新配置的PRF唯一来源为`acquisition.period_ns`，旧`timing`字段经兼容层迁移。C由帧率与帧数确定测量时间范围，按名义触发时刻生成真实时隙，不允许独立设置累计发数。预热周期来自算法配置，位于测量帧之前，不计作测量发数。

## 新工作台与默认值

页面按扫描机构与同步、Tx、场景/运动、Rx、SPAD、读出、环境光、采集时序分类，使用与B相同的青色标题、折叠控件和结构化输入。共有默认值继承初版A，包含开启太阳及其他环境光。默认多发扫描的背景候选下界会超过当前事件限额，预览据实显示，不自动减小发数或关闭背景；可显式载入YAML中的“快速扫描示例”（关闭两类环境光）。该示例不是隐含默认值。

帧、扫描角bin和读出通道联动到实际发数、距离分面、点云和探测直方图。点云支持X–Z/X–Y/Y–Z投影，保持等比例空间坐标；距离分面可统一坐标轴，源加权真值只作可选审计。图旁有精确时间输入，全门概览的橙色窗口可拖动。逐发像面按明确的参考时隙查看，并可恢复全采集的发射均值。

当前参数轨迹预览和已保存采集结果可分别查看。C当前保存单次扫描，不从单次观测推造重复统计；未保存的逐角理想参考、纯噪声均值和误差棒层明确禁用。数字重放使用同一记录重新分箱并重建距离与点云，原始导出不变。

静态PSF/dB面板是局部角域参考，与扫描全局角bin选择分别标识。所有空间图右正左负、上正下负；历史结果保留原坐标定义并标注，新的配置和光学数据使用版本3/版本2契约。

| 轨迹 | 定义与有效区 |
|---|---|
| static | 机械角固定在起始角，所有时隙属于有效段 |
| sawtooth | 按active_fraction线性前扫，其余时间连续线性回扫 |
| triangle | 前半周期正向、后半周期反向，双向均为有效段 |
| sinusoidal | 余弦形式往复扫描，双向有效；端点驻留自然增加 |

机械角通过明确倍率和零点映射为光学角。控制计划不使用真实机械相位偏移；实际镜面轨迹包含该偏移。因此，控制器可在实际回扫时误发，审计会记录这一点。

`active_only`只在控制计划有效段启用激光；`continuous`在回扫也启用。无论是否启用发射，周期器件门和读出门继续运行，SPAD/TDC不会因换角、换帧或回扫而复位。`free_running`时门外背景和DCR也影响恢复状态。

实际发射时刻包含固定偏移和独立随机流的时间抖动。编码器角标签使用其延迟和角度偏差后的读数。真实发射、名义触发、编码器标签分开保存，不用真实发射误差自动修正测距。

这里的发射时刻指时间波形中心。完整脉冲计账与有限时间窗内的Tx能量积分分别输出；平均功率按真实波形在时间窗内的积分计算。中心在边界的高斯/矩形脉冲不会被补成完整窗口内能量。编码器延迟可正可负，负值用于研究离线时标错配到后续角样本。

帧标签按触发参考时刻归属；光子和TDC状态在绝对时间上连续。记录不会得到隐藏的源脉冲身份。超出一个PRF周期的回波可能发生距离/脉冲混叠；当前未实现编码消歧。

## 发射和接收时刻的光学状态

每发将Tx局部角分布转到真实全局H方向，在构造场景中求反射距离，再以各角单元的回波到达中心求Rx指向。Tx中心姿态和Rx回波姿态是两个不同时间的状态。

采用近轴H角相加、V不变的组合，不是三维镜面法线光线追迹。有限脉宽内仍采用中心姿态近似，没有展开脉冲内部的连续角运动。

Rx可共扫、部分跟随或固定。Tx角域与构造Rx数据库覆盖域现已独立；Rx角度/波长超域会明确失败，不自动外推为零或重归一化。实际光线在数据库覆盖内、但PSF落到阵列外的能量则正常记作边缘损失。

旧完整B配置原先耦合Tx/Rx域，迁移逻辑只在 `legacy_config` 中补出对应Rx域。新配置显式保存两个域，不靠H/V binning猜IFOV。

## 构造场景和背景

场景用基础径向距离、全局H角距离梯度和恒定径向速度描述。移动目标的反射距离按出射光与目标的截获关系求解；同一发的不同H角可以具有不同到达时刻，不会先把所有光子压成同一个回波中心。

这是局部正入射朗伯距离场，不包含遮挡、目标法线变化、横向运动、相对论辐射或多普勒谱移。真值距离仅参与光子生成和误差审计，距离估计器只能看到采集记录和已知脉冲/电子学参数。

背景在接收机局部角域内均匀平稳，延续B的角网格域和光谱口径，不随Tx能量份额或发射开关缩放。太阳、其他光、DCR和其他电子候选分别审计。末帧的非整周期记录门按实际截止时间截断，记录requested/effective差异，不补回曝光或光子。

所有跨页面/文档公式均维护在 `config/formulas.yaml` 与 `formula-notes.yaml`。C的展示流程位于 `photon-flow.yaml` 的scan分支，并随 `docs/photon-budget.md` 生成和校验。

## 角bin、距离线图和点云

角bin、时间帧及门使用左闭右开约定，最后右边界也不包含。极小的角度浮点边界误差按 `scan_angle_boundary_tolerance_mrad` 处理，只作用于归属，不改变实际光学角。每发保存修正量；算法设为0可使用严格浮点比较。

同时输出三组计数：

1. 真实时间/方向下的全部实际发射。
2. 真实有效段内的有效发射。
3. 控制参考帧、编码器角标签下分配给重建的发射。

重建只使用第三组规则，不读取隐藏真值去剔除误发。关闭 `reconstruct_flyback` 时，仅剔除控制计划中的回扫时隙。光子实际到达哪个触发周期，由连续事件时间及TDC门决定。

累计数组轴为 `[frame, scan_angle_bin, readout_channel, time_bin]`。同一发同时照射多个读出通道，不能把各通道发数相加当成总PRF发数。空角bin保持零曝光计数；没有距离输出时保持null，不填造点。

通道方向可以显式标定，也可以使用均匀角场下按Rx效率×PSF×立体角加权的局部角质心。没有光学响应的通道不猜方向。重建使用触发参考的编码器方向，没有逐光子飞行时间内姿态补偿或通道角融合。

当前距离线图和XYZ点云都是未经检测门限判定的原始估计，没有C专用Pd/PFA。负距离或超出前向坐标域的方向保留原始值及无效标识，但不输出点云。误差参考是源信号光子加权的真值距离；RMSE只统计有数值估计且有源信号参考的格点，不代表检出概率。

## 网页和数据复查

- “预览轨迹与发数”只调用Python时序与计数核心，不生成光子或假直方图。
- 完整运行后可切换帧、角bin、通道，查看局部直方图及逐发像面光子图。
- “重放扫描重建”只重分箱同一份TDC记录。CSV导出采用当前重放分辨率；原始完整JSON始终保留原采集记录与结果。
- 结果包含实际/名义时序、回波时刻Rx姿态、逐角反射距离、光子分量、每发能量平衡、帧/角/通道直方图、原始记录、点云、seed、完整配置和算法指纹。
- 背景原始光子数注明积分波段；背景总量按记录门实际长度求和，free_running门外候选另见事件审计。

## 自动验收与限制

`tests/test_scanning.py` 覆盖七种模式静止退化到B的逐记录一致性、真实驻留发数、回扫、跨角/跨帧死时间、编码器与激光误差、非匀速轨迹、部分门、径向运动、Rx覆盖、分块一致性、真值隔离、重放、CSV及B→C配置转移。

还保留A八种模式、B七种数字模式的修改前数值快照。整体截图、配置、完整数组、点云和验收记录位于 `artifacts/scan-upgrade/`。实际整机验收仍需用真实转镜映射、同步误差、场景与光学数据替换构造参数。

尚未实现的真实性扩展：跨读出组共享TDC、动态/重叠ROI、afterpulse、雪崩串扰、厂商特定FIFO、三维场景遮挡、横向目标运动、逐脉冲内光学积分及编码距离消歧。后台任务中断后仍基于配置重新提交，不宣称进程崩溃自动续算。
