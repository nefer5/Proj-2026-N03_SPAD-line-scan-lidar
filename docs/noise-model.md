# A版当前噪声计算

本说明对应当前Python实现，而非未来计划。光学链路公式见 [光子预算](photon-budget.md)，谱积分见 [光谱与背景](spectral-background.md)，事件竞争见 [读出模式](readout-modes.md)。核心入口为 `simulator.py:photon_budget`、`spectra.py:spectral_components`、`readout.py:event_histogram/route_events`。

## 1. 四类噪声先算候选率

| 来源 | 当前计算 | 是否乘PDE/FF |
| --- | --- | --- |
| 太阳反射光 | 标准/自定义太阳谱按目标面lux归一化，乘灰反射率/π得到朝Rx的谱辐亮度，再做接收链谱积分 | 是 |
| 其他环境光 | 输入直接为接收方向谱辐亮度，乘用户倍率，再做同一接收链谱积分 | 是 |
| DCR暗计数 | 每SPAD固定暗触发率 × H/V binning乘积 × 门宽 | 否 |
| 其他电子随机噪声 | 每SPAD额外独立触发率 × H/V binning乘积 × 门宽 | 否 |

其他环境光不是“其他电子随机噪声”：前者有光谱并经过滤光片，后者是器件事件率，不能靠光学滤波去除。

太阳和其他环境光各自的每门候选数是：入瞳面积 × 通道立体角 × Rx效率 × 门宽 × FF × 对“谱辐亮度 × 滤光片透过率 × PDE × 每焦耳光子数”做波长积分。完整公式及符号单位统一见光子预算中的 `budget_background_candidate`。输入谱辐亮度单位为W/(m²·sr·nm)，波长积分按nm，光子换算使用10⁻⁹λnm/(hc)。

这里只计算期望雪崩候选数，不是已经过死时间和读出后的计数。光学背景按整个角通道预算，不再乘SPAD总数；DCR和其他电子噪声是单SPAD率，因此要乘总数。

定义N为H_binning×V_binning，Tg为以秒计的门宽，rD、rE分别为单SPAD暗计数和其他电子噪声率（s⁻¹）：

$$
\mu_D=r_DNT_g,\qquad \mu_E=r_ENT_g
$$

μD、μE是每门无量纲期望事件数。总噪声候选数μn为太阳、其他环境光、DCR、其他电子噪声四项之和。

## 2. 从期望值抽样出事件

事件模式每个周期独立抽取信号数和噪声数：

$$
N_s\sim\operatorname{Poisson}(\mu_s),\qquad
N_n\sim\operatorname{Poisson}(\mu_n)
$$

Ns/Nn是本周期随机候选数，μs/μn为对应均值。泊松数的方差等于均值，因此信号本身也有散粒噪声，不会在信号上再叠加一次“sqrt(N)高斯计数噪声”。

- gated模式：噪声事件时间均匀分布在门内。
- free_running模式：候选率换算到整个PRF周期，门外也产生噪声雪崩并影响随后门内的SPAD可用性。开始有有限预热周期，数量来自algorithms.yaml。
- 各候选事件随机、均匀分配到本通道N个SPAD。这是A版均匀照明假设，没有二维PSF和热点像素分布。
- 四类噪声在预算中分别计算，但生成时合并为一个泊松过程。对于独立、均匀泊松源，这是有效的总事件分布；当前不保留每个事件的来源标签。

之后按时间顺序处理：SPAD恢复 → OR/符合/独立逻辑 → TDC恢复与每周期容量 → 成功时间戳 → 量化直方图。非延长型死时间表示恢复中被拒绝的候选事件不重启恢复计时。TDC拒绝一个事件并不撤销已发生的SPAD雪崩及其死时间。

因此最终输出一般不再是简单的独立泊松直方图。不能用“信号+噪声记录数减噪声独立记录数”当作严格的已记录信号数，因为两者会竞争。

## 3. 时间噪声与计数噪声分开

信号到达时间由真值飞行时间、激光时间波形和SPAD高斯抖动组成；其他电子高斯抖动只加在成功记录的时间戳上，之后用实际TDC bin边界计数。

高斯FWHM与标准差关系如下，二者必须采用相同时间单位：

$$
\sigma_t=\frac{\mathrm{FWHM}}{2\sqrt{2\ln 2}}
$$

173ps的SPAD FWHM对应约73.5ps标准差。当前仅支持高斯SPAD抖动，不能单独设定FW10%或非高斯长尾。噪声时间因采用平稳均匀近似，不逐事件额外加入SPAD抖动；门边沿器件瞬态未模拟。

TDC的1000ps是量化格宽，不是另一个1000ps高斯抖动。它对应约14.99cm的距离格宽，但不意味着质心估计精度一定等于14.99cm。理想扫距精度另用Δt/√12估算量化标准差；实际事件直方图不再额外抽一次这种量化噪声。

## 4. 默认工况的可复核例子

本次审视时本地配置为：16个SPAD、2048ns门宽、30发累计，DCR=2007cps/SPAD。太阳50000lux，光谱/光学沿用本地配置。以下只是该配置快照的计算例子，不是第二套运行默认值。

| 来源 | 每门候选期望数（读出损失前） |
| --- | ---: |
| 太阳反射 | 5.879257 |
| 其他环境光 | 2.284564 |
| DCR | 0.065765376 |
| 其他电子随机噪声 | 0 |
| 合计 | 8.229587 |

DCR手算：2007×16×2048×10⁻⁹=0.065765376/门，累计30发为1.97296128个候选。实际记录还要经过模式相关竞争。这一工况中光学背景远高于暗计数，缩小IFOV、滤光带宽或合适的时间门可能比继续降低DCR更有效，需用实际读出模式验证。

## 5. 图上的噪声曲线与解析参考

事件模式橙色噪声曲线由关闭激光后的独立实验均值获得，重复数来自 `readout_expected_trials`（本次为24）；它不是当前观测中逐事件分离出的噪声。每张噪声图统计与累计发数相同数量的接收门，没有发射信号光。当前青色曲线为纯信号解析ground truth，与24次均值无关。蓝柱为首次观测，测距统计总次数大于0时包含这次观测，再由独立重复随机流补足剩余次数；同批统计也生成逐bin最小–最大误差棒。内部混合均值、噪声均值另有各自的随机流。详见histogram-display.md。

`analytic_reference`不同：每SPAD每发理想复位，只取首事件。每bin事件均值μk确定首事件概率pk：

$$
p_k=\exp\left(-\sum_{j<k}\mu_j\right)(1-\exp(-\mu_k))
$$

k/j为时间bin索引；pk为本周期首事件落入bin k的概率。联合“无事件”类别做多项分布抽样，次数为N×累计发数。有限SPAD/TDC死时间、OR、符合等不用于这个解析参考。

## 6. 尚未包含与指标限制

- afterpulse、雪崩诱发串扰、延迟反射/多径、其他LiDAR的同步干扰、慢漂移、温度/过压联动、热像素分布尚未实现。
- 专家页串扰矩阵是独立分支期望诊断，未注入A版直方图。
- 目前测距为背景中值估计、平滑找峰、局部非负质心，没有经无目标实验标定的检测门限。纯噪声也可能输出距离。
- 成功率只是相对已知真值在容差内的次数比例，不是正式Pd；峰值评分不是PFA标定后的SNR。少量MC不能证明极低虚警率。
- 调试逐bin概率列是理想首事件参考，不能用它替代共享TDC/符合模式的真实事件分布。
