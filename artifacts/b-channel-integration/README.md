## 交付内容

- `web/shared/channel-locator.js/.css`：独立的展示组件；Python 提供布局、实际像素边界和光子汇总，宿主统一持有选择状态。
- 通道列表、像面图、直方图、CSV 导出共用 `selectedChannels`；保留精确时间输入、全门拖动、统计图层和已有记录重放。
- 细网格、光斑开关、不透明度、悬停详情、键盘选择及等比例坐标均已接入。
- 布局、全光斑和直方图绑定同一个任务/配置指纹。编辑草稿只更新参数预览和汇总，原采集图不变；新采集完成后整组切换。
- 历史文件不重写、不重采样；`system-view` 在读取时生成显示元数据。旧周期 C 继续使用原控件。
- 编号公式和说明使用共享 `b_readout_channel_index`，新 JS/CSS 均通过内容指纹加载，开发响应禁用缓存。无新增仿真默认值或物理算法。
