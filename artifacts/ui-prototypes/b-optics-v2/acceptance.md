# B 前端原型 02 验收

此次更新范围：前端原型、离线样例生成器、参数帮助元数据。正式模型与 API 未改动。

已完成：

- 水平和垂直等效焦距分别输入，初值从原 YAML 标量焦距派生。
- 固定样例使用两轴倒置成像。正 H/V 对应负 x/y；原型所有空间图上正下负，通道身份不重新编号。
- 七类参数中的共有默认值继承初版，包括1发、太阳开启、其他环境光开启；新光学参数继承原 B 样例。
- 十类可折叠参数图，原初版五类全部覆盖；共用 Python 曲线数据，前端不生成物理波形。
- 当前角单元的 dB 空间分布和条件通道比值矩阵；可切换参考通道，10倍功率对数定义、20倍幅度定义及零值边界均有注释。

数值验收见 `numeric-verification.json` 和可复跑脚本 `verify_snapshot.py`：共有默认值一致、全部角单元成像符号、PSF能量守恒、-10/-20 dB基准及零值边界、合成背景谱/PDE×FF一致、首次观测位于误差棒范围内。

实际浏览器验收：10个参数图标签切换、两焦距独立输入、KaTeX公式渲染、上正下负的网格定位、正角→负像面的联动、6×6通道比值矩阵、参考切换和零参考未定义提示。普通刷新载入02版；旧原型草稿不覆盖新默认值。

样例说明：现在使用初版默认背景和1发，首次最终记录9392条，包含背景与信号混合竞争，不能当成信号计数。统计仍使用YAML中的40次含信号采集、24次关激光采集。

当前仍是固定样例原型。f_H/f_V配置类型、正式几何符号/坐标契约迁移和交互重算，待后续后端实现。
