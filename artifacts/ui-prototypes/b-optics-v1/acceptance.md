## 实际浏览器检查

通过已安装的 Tabbit 本地接口执行原生 Playwright 操作并查看截图：

- 七个参数分组的全折叠、全展开及结构化 Tx 角域输入。
- 能量草稿改动后提示结果过期；刷新后草稿保持，图表固定；恢复样例正常。
- 太阳与其他环境光启用后各自的配置显示，关闭后收起。
- 圆形入瞳和 Rx 数据库模型切换时，相关参数显示状态正确。
- 输入 `0,2,4-5` 显示四张分面图；非法通道报错，不偷偷替换输入。
- 时间窗口缩放、误差棒图层开关、全门概览。
- 二维角单元选择驱动 PSF 与通道份额联动；角落截获比例 71.85%，中心 100%。
- 运行按钮明确打开“前端预览阶段”提示，不发送仿真任务。
- 1440、1024、768、390 像素宽度无页面横向溢出；桌面图形经截图检查。
- 无浏览器脚本异常；入口 HTTP 200，缓存策略 no-store。

浏览器操作程序保留为 browser-*.js，截图同目录保存。

## 数据检查

固定样例由已有 Python 核心生成，首次采集 1497 条记录、SPAD 死时间损失 293 条。
40 次含信号采集的逐 bin 最小—最大范围包含首次观测；纯噪声均值使用 24 次独立采集。次数源自现有 YAML，未在原型中新增仿真默认值。

误差棒为样本范围，不是置信区间。修改原型输入不更新这些结果。
