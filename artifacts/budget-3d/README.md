# 系统预算三维示意验证

2026-09-28，已实现并自验；用户人工验收待进行。

## 功能与边界

- 正式入口 `/system/budget` 顶部“参数的三维含义”。本地Three.js和OrbitControls，通过内容指纹资源及import map加载。
- 展示VCSEL、转镜/角度原点、Tx归一化域与相对角密度、Rx接收域/入瞳、SPAD像素能量和目标平面。
- 表单focus高亮关联部件；三维部件标签/按钮反向定位表单；透视、角域正视、探测器视角；传播动画播放/暂停。
- 后端使用同次B光学结果派生展示数据。横向/纵深缩放分开并显示倍率；器件位置为展开示意，不表示实际基线或共轴关系。
- 动画仅解释关系，不按真实光速或光子数播放。无共同采样角不画返回路径；0功率禁用播放。
- `budget_schematic_max_cells`是显示上限，超限不降低实际计算采样；转为通道格或轮廓时显示明确说明。
