# 双轴空间模型与B布局优化验收

日期：2026-09-25；模型版本：0.6.2.dev0。

## 已实现

- Tx新增`super_gaussian`，H/V独立FWHM、中心与阶数；配置角域内积分归一化保留。
- Rx新增`super_gaussian_psf`，H/V独立实际标准差与阶数。指数使用2m，m=1退化为高斯，有限像面外能量不补偿。
- 高斯Rx也改为σ_H、σ_V。旧`psf_sigma_um`在兼容层等价迁移到两轴；新旧混用报错。既有高斯默认值保持原行为。
- B与C均使用同一公共数值核心。新增默认值只在defaults.yaml；阶数上限、显示采样数/范围/裁切分位只在algorithms.yaml，类型、参数帮助和调试输出同步。
- PSF基础参数图显示独立密度分布，不叠加通道；H/V剖面使用交错圆点/菱点与不同虚线。相同数据自然重合，不平移曲线。
- Rx焦距、像面偏移、PSF标准差和阶数、入瞳全尺寸以及Tx可分离参数按H/V成组。C通用表单同步成组。
- 角单元与读出份额左列堆叠；右列PSF通道投影纵向加长。窄图减少横轴刻度，避免重叠。
- 串扰布局由1:1.45调整为1:2.7，左列占比约由40.8%降至27.0%，约缩减三分之一。
- 局部直方图高度从234px增加到桌面360px；窄屏300px。全门概览和逐gate累计图维持各自高度。

## 数值验证

`tests/test_spatial_profiles.py`新增10项：密度积分、方差、FWHM、m=1高斯极限、尾部质量非负、双轴独立、Tx归一化、Rx边缘损失、迁移/混用错误、枚举与阶数上限。

完整测试278项通过；历史结果适配只更新显示元数据，不重算光谱或通道矩阵，随后又通过27项B相关定向回归。光子预算文档同步检查通过，空间模型文档由共享公式生成；VS Code数学渲染库解析80个公式通过。

`verify.py`使用用户任务`90e9141e1ad34cf3b21a693788a1de41`：迁移后的高斯物理像素PSF、信号光子数组和全部采集记录逐项完全一致。另执行B双轴超高斯完整采集和具名快速工况下的C超高斯采集。完整配置、算法、版本、时间、源SHA256与数值证据保存在`verification.json`；原始用户任务文件未修改。
