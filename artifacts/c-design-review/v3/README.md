# C 设计预览 v3：High Level 系统预算

日期：2026-09-25。入口：`http://127.0.0.1:8016/static/prototypes/c-exposure/index.html?revision=03`。

本轮按用户要求将 T_slot 作为高层下发的目标：顶部收集帧率、HFOV、扫描时间利用率、slot数量，展示帧时间分配与每列最大时间，再通过下发交互向下层传递只读目标。正式预算求解与新列计划尚未接入。

## 定义与边界

- 当前参考均匀分配：1000 Hz、40 mrad、80%、20列 → 1000 μs帧周期、800 μs扫描可分配时间、40 μs列上限及目标，角格宽2 mrad，平均光学速度50 rad/s。
- HFOV在固定列数时不直接改变列时间，在固定角步距时通过列数影响时间。N表示覆盖角格数，不使用包含两个端点的N点间距约定。
- 目标下发不等于满足目标；DSP/MIPI延迟、吞吐与缓冲需分别核对，不能简单将采集/DSP/MIPI耗时相加。
- 如果未来下发小于等分上限的列启动周期，实际扫段缩短，应按列数乘目标周期重新计算扫描速度。当前参考采用上限，未额外预留余量。
- 高层输入改变后，旧目标有效性被撤销，输出显示待计算，下发按钮禁用；不假装前端已经计算新预算。左侧旧参考帧率、利用率和角格宽只读。
- 数值来自Python；三条公式来自`config/formulas.yaml`，定义来自`formula-notes.yaml`，使用本地KaTeX实际渲染。
