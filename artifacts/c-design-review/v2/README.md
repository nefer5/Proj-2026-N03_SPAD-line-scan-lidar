# C 前端设计预览 v2：运动、逐发计划、DSP / MIPI

2026-09-25。预览入口：`http://127.0.0.1:8016/static/prototypes/c-exposure/index.html?revision=02`。

用户确认：双缓冲；采集下一列时可处理/搬运上一列；MIPI 在 DSP 后向主机输出结果。当前仍为设计审核，不接入新的生产仿真调度或资源队列。

## 新增内容

- 转镜机械角速度、Tx 光学角速度、列内相邻发射角差、全帧速度曲线。
- 逐发、逐距离的光学飞行时间、Rx 到达姿态、相对入射角与倒置成像位移。复用 Python 的 mirror_pose、reflection_range、image_center。
- 可增删的逐发时间/能量表及 JSON list。ns 相对列开始，nJ 为 Tx 光学前全光斑能量；明确校验逆序、重复、非有限、越界和未知键；支持空列表与暗触发。
- 两列时序的 Tx 草案、DSP、MIPI 三条泳道。处理块保留数据列标签，显示上一列与当前采集的重叠。
- DSP/MIPI 输入时间初始为空。预览只按输入位置绘图，不求解真实队列、吞吐、缓冲冲突；不把草案误当成新的回波或探测结果。
- 新设计输入的单位、约束及是否生效已写入 `config/parameter-help.yaml` 的 `design_review` 区，不在 SimulationConfig 中伪装成已实现配置。

## 验证

- 既有扫描与 C 工作区测试：32 passed（37.83 s）。正式数值核心未修改。
- `python artifacts/c-design-review/v2/check-reference.py`：验证角倍率、量纲、发射角差、飞行时间、正负号、倒置像移、静止极限、电子标定延迟不改变机械飞行姿态，以及跨转向点必须查询真实姿态。
- 当前参考结果：机械25 rad/s、光学50 rad/s；10 μs相邻发射角差0.5 mrad；100 m飞行667.128190396 ns，Rx转角+0.0333564095 mrad，倒置运动像移+0.6671281906 μm。
- 实际浏览器：距离与发射联动、表格/JSON、重复时刻报错、未知键报错、空列表、暗触发、非法列表时切换列、DSP/MIPI先后依赖、前一列处理块、精确时间窗、增删恢复、折叠、普通刷新均检查通过；无页面异常，无生产 POST。
- 移动端390×844：曝光与资源规划工作区的页面宽度均为375 px，无页面级水平溢出。详细表格与时序允许局部横向滚动。
- CSS、两份JS和数据均保留内容指纹；服务仍使用8016。
