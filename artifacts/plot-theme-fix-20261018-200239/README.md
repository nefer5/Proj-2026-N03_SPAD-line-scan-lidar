# 三维坐标叠层与图表主题修复

日期：2026-10-18。用户截图报告三维世界轴异常放大并遮住场景、浅色直方图网格/坐标过淡。现行约束维护在[界面规范](../../docs/design/ui-design-guidelines.md#固定坐标叠层与图表对比修复)。

## 原因与修复

通用SVG可读性增强误包装了绝对定位的三维HUD，普通科学图的100%宽度/自动高度覆盖了其角落尺寸。复现时HUD为1367×1201.5 CSS像素，遮罩背景同时盖住主场景。现在固定叠层以data-figure-layout明确排除，绝对/固定定位SVG也不进入通用文档流布局；HUD保留右下角148×130的组件尺寸，移动端使用独立尺寸。HUD逐帧更新不再触发普通图表增强。

浅色网格原先沿用自动反转色，深色细线被转换为近白。现在build-theme.py统一定义网格、主轴、文字与三维地网角色色，Canvas按LidarTheme.plotColor读取，细节SVG同步使用角色色。直方图保持13px轴文字，按数字宽度留白，端点刻度对齐，主轴单独绘制；数据曲线及物理坐标不改。共享绘图器一同修复，避免同问题在其他平台再出现。

## 实际验证

- audit.ps1及check-budget/check-histogram.js为可重跑的浏览器检查（需当前项目8016服务及agent-browser）。深浅主题×1920×950/1536×760/1280×620，共12组检查。
- 每个三维用例核对整机/局部两种范围、五个相机方向，共60个相机状态；检查HUD直接归属于sceneViewport、固定尺寸、未进入通用图卡、文字及框均未裁切；另检查传播动画和主题切换没有预算计算POST。
- 直方图核对主题、实际颜色对比、13px文字、观察窗口不随主题改变、窗口调整不提交采集及页面无横向溢出。浅色网格/轴/文字对比约3.16/6.21/8.33，深色实测值见各JSON。
- 主线程和视觉专家实际查看三维与直方图深浅截图，确认无巨大坐标、场景遮罩或明显坐标/单位裁切，网格清楚且不压过数据曲线。截帧复审与程序视角覆盖分别记录，不互相替代。
- pytest.log记录491项回归通过；主题生成与光子预算文档同步检查通过。所有Python计算源码及配置YAML与before-hashes.json逐字节一致，见validation.json。
