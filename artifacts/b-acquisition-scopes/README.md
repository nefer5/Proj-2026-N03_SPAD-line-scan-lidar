## 数据边界

当前B只保存首次采集的逐事件记录和各轮slot折叠直方图，未保存逐gate重复统计。因此单gate误差棒明确禁用，不重跑、不平均或推造。单发理想信号只描述本次Tx的解析参考，不包括其他曝光的迟到回波。历史任务缺少统计数据时，M显示“未保存”。

B的slot显示口径是本次N发序列；长度为N个发射周期，并不是新增的独立硬件T_slot上限。说明中的列间复位/DSP/MIPI表示已讨论架构，复位耗时与完整C帧预算仍未接入计算。
