# 带外透过率、每time_bin计量与折叠标题验收

2026-09-25，模型版本0.6.3.dev0。

## 每time_bin计量

按用户澄清，只做解析乘法：PDE/FF后的源背景候选计数率 × time_bin时长。无额外随机采样或统计，不由gate、曝光、累计发数N或重复次数M决定；不含死时间或电子读出损失。B/C保持原光学预算的全阵列汇总范围，A为当前角通道。

太阳与其他环境光各在核算末尾新增一行，使用原始TDC分箱时长并在说明中标明。历史文件只读补充显示行；历史只保存了每门期望时，通过其原始参考时长还原计数率，这是单位转换，不是从观测记录估计统计均值。

原任务`3440493ef4be44c98130ae74e1451805`，time_bin=1000ps：

- 太阳：1.6448628912656376 candidates/bin。
- 其他环境光：0.07101795779183356 candidates/bin。

测试验证：修改gate宽度、N、M均不改变上述解析值。

## 滤光片

- 仅基础滤光片新增out_of_band_transmission，默认值唯一写在defaults.yaml。
- constant、rectangle、gaussian、cosine_flat均支持；T=T_out+(T_peak−T_out)F，带内峰值保持原值，母函数定义范围外使用带外透过率。
- 高斯FWHM指扣除带外基底后的母函数宽度。参数图保持局部形状可读，实际积分范围另外显示。
- 要求0≤T_out≤T_peak≤1，拒绝越界及非有限值。CSV/手动模式只用当前采样曲线，不叠加基础值。
- 非零带外值覆盖已提供的太阳/环境光源范围；本例为280–4000nm。导入Rx表只计算其已知波长范围，并明确审计未建模区；不把未知响应外推或宣称为完全阻断。
- 构造Rx的无色差特性允许精确分离空间和光谱；保留完整波长节点、入射光子及PDE响应，无近似降采样。导出outer_product包含完整重建因子，dense()或numpy.outer可恢复矩阵。导入Rx仍逐波长计算。
- 带外值为0，原有限波段及采集记录完全保持。

## 原值1.644863的收光与像素范围

这个原任务是零带外透过率、855–955nm积分、900–910nm通带，直径20mm圆形入瞳，Rx效率0.8，FF=1。背景积分角域H=[−1.5,1.5]、V=[−1,1]mrad，对应6e−6sr。光学映射使用f_H/f_V和σ_H=5μm、σ_V=8μm的PSF，并按真实像素边界积分；99.433%的滤光后光子被有限阵列截获，再经波长相关PDE与FF。

1×9通道、每通道8×4 SPAD，共288个物理像素。逐像素候选率相加，再乘1ns得到全阵列1.644862891候选/bin，没有额外乘像素数。原任务太阳分量：CH04为1.324437201，CH03/05各0.160209848，CH02/06各约0.000002997，其余极小；不是均匀分摊到所有通道或像素。

模型限制：目前背景角域沿用Tx网格，尚未独立建模完整Rx环境视场。上述值是有限场景角域贡献的全阵列总量。若环境实际填满更大的Rx视场，域外背景没有计入，不能把此值当成完整环境总噪声。
