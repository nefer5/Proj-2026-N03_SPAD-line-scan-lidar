# 固定分工双缓冲 · A采集 / B处理

按用户最新架构说明修正，仅独立预览，未接入正式网页。

A始终接收slot原始Hist，整块搬至B并清空A后，A开始下一slot；DSP始终处理B。这里与A/B交换采集、处理角色的经典乒乓预览不同，v2保留为历史方案。

约束：

- A采集不能覆盖尚未搬完的数据；下一次采集必须等待A→B搬移完成及A清空结束。
- A→B搬移必须同时等A数据就绪、B可覆写、搬移资源空闲。
- DSP在B搬移完成后开始；本例保守设为结果入输出FIFO后B才可覆写。
- 输出FIFO有限，按整列结果块保留到发送完成。满时保留B结果，进而阻塞A→B搬移和后续A复用。
- 示例逐时刻验证了前述依赖与FIFO容量：采集开始0/95/205μs，S2相对目标160μs延后45μs；S1、S2各等待FIFO60μs；FIFO最多1块。

演示值：采集80、整块搬移10、A清空5、DSP100、打包10、发送160μs。搬移期间两缓存均被占用，不假设分块搬移或并行改写。此处不是芯片规格、正式默认值或协议预算结论。

所有方块为直角，依赖竖线连接真实交接时刻，不同交接时刻之间的等待以正交虚线表示。
