## 实现与边界

- 共享直方图、数值曲线与A波形/扫参图统一使用淡虚线辅助网格；缺失的另一方向已补齐。SPAD直方图、扫描/点云显示同步调整；SVG参考曲线补齐网格并把实线坐标轴绘在网格之后。
- --plot-grid-dash统一Canvas和SVG的线型。绘制网格后重置Canvas虚线状态，坐标轴保持实线，主直方图轴宽仍为1.25px。数据参考曲线自己的实/虚线、误差棒和真实单元边界不随之改变。

- 所有计算Python源码和config YAML逐字节保留，颜色/网格只影响显示。
