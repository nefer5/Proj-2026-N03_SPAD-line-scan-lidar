日期：2026-10-18。本目录记录此项功能，不替代现行配置说明。

实现前工作树保存在before.zip，包含当时的源码、前端、YAML与文档。测试使用serve-isolated.py在18765端口运行，所有默认写入仅进入isolated-config，备份仅进入isolated-backups。正式config/defaults.yaml逐字节保持不变。

## 自验

- 单元/API测试覆盖六个兼容kind：归属、反向周期单位换算、共享传播、预算专用覆盖、C逐发列表、CSV/手动独立保存、原始字节备份、无变化不写、指纹冲突、非法值/重复键拒绝、跨平台非法拒绝、已有冻结快照不变、跨来源写入拒绝和资源内容指纹。
- agent-browser在1920×1080实际访问A、独立SPAD、B、C、预算页，修改参数→预览→确认写入→普通刷新/恢复默认→读取新值。A额外验证取消；B/C/预算验证原生表单change事件。A/B共享距离依次保存为隔离值，SPAD保存专用直接照明，C保存专用重复次数，预算保存VFOV并检查派生域。
- a-confirm.png、c-confirm.png、budget-confirm.png为实际审查窗口；budget-720p-confirm.png验证1280×720下确认窗口没有裁切或横向溢出。预算VFOV的预览仅写几何参数，但明确显示五项解析结果变化；C专用值只影响C。
- 首轮全量结果462通过、1失败，原因是旧测试的临时资源清单遗漏新公共JS/CSS；补齐后定向21项通过。最终全量464项通过，见full-suite-final.log。
- 公式生成同步检查通过；当前文档链接与正式默认不变检查见validation.json。

## 使用与恢复

五个平台“恢复默认”旁点击“设为默认”，审查字段归属与影响范围后确认。新默认是整个项目的默认，共享字段会传播到继承平台；旧表单需点击恢复默认，已有任务不受影响。原始文件与receipt备份到artifacts/defaults-backups，按现行[配置说明](../../docs/guides/configuration-and-data.md#将本页参数设为项目默认)恢复。
