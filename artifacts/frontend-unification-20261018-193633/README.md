## 实现

- webapi/chrome.py统一服务端导航，当前项为真实disabled按钮及aria-current，其他四项保留真实链接；主题按钮独立在右侧。
- shared/workspace.css统一阅读尺度：正文15px，标签14px，输入15px/至少36px高，帮助和单位13px；局部旧微小字号按角色提升，保留原有矮窗口整栏滚动。
- Canvas使用CSS像素字号和原DPR缓冲；SVG按实际缩放后的字形检查，取消固定高度导致的二次缩字，必要时图卡内部滚动，保留viewBox和物理比例。
- B窄像面的通道文字不再堆叠：容不下时转为像素悬停/原通道选择器核对，精确坐标范围仍显示；未拉伸像面或改数据。A坐标标签避免右端裁切。
- SPAD历史默认折叠，运行时展开，完成后收起；查看结果、刷新和取消控件保留。实际采集图见spad-live-result.png。
