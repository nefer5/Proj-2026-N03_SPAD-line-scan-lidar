## 已修复的问题

原 `renderParameters()` 从可编辑 `draft` 生成输入框，却从此前显示的 `data/base` 生成布局说明。`saveDraft()` 和采集完成时的 `showModel()` 都没有更新该说明，因此新输入和新结果旁仍可能保留旧布局。原采集保存的阵列、通道分组和直方图是正确的。

现在由 Python 从实际 `pixel_group_ids`、`array_shape`、Rx 像素边界生成 `readout_layout`；参数汇总读取对应当前草稿的已校验预览。更新中或校验失败时明确显示状态；如果已采集结果与当前布局不同，另外标明已采集布局。历史记录不重采样、不重写。

## 界面约定

- 左侧输入通道号或范围、点选列表；右侧像面网格可反向点选，键盘 Enter/空格可操作。列表、像面高亮和下方直方图使用同一选择状态。
- H 向右、V 向上，索引从零开始，H 优先编号。下方为负坐标。保持实际 Rx 像面比例，不拉宽窄线阵。
- 光斑底图为该工况整束信号光在感光面完整物理像素内的光子积分，参考面位于 PDE/FF 前。提供绝对色标、开关和不透明度；当前 FF 模型没有定义像素内部有效感光区域形状，界面不补造这种几何。
- 粗线表示读出通道，细线表示物理像素，可关闭细网格。详情显示 H/V、SPAD 数、实际坐标边界、通道光子数和记录数。
- 直方图复用 `PhotonHistogram`，包括真实计数、解析信号、独立纯噪声均值、样本最小—最大误差棒，以及全门拖动和精确时间输入。
- 这是来源固定的设计预览，不能启动新仿真，不改正式页通道选择界面或仿真默认值。
