# 数值显示与浅色分组改进

本轮实现并自验，用户人工验收待进行。未实施模型重构或C电学扩展，未修改仿真默认参数。

## 改动

- 五个平台共享简洁数值格式：普通数值最多两位小数、去掉尾零；非零绝对值小于0.01或大于等于1e6采用三位有效数字科学记数法。表单、时间窗口及若干结果表和图形标注共用规则。
- 输入框独立保留完整数值。A实际边界660.302830724201–673.953550068407显示为660.3–673.95，直接应用后完整边界逐值不变。明确输入660.345678901、实际移焦后显示660.35，读取仍为660.345678901。完整JSON/CSV/数组和审计导出保持原始精度。
- 浅色使用灰蓝页面底、白主面板、灰蓝参数模块标题、浅灰子组及白输入框/明确边界；深色原配色保留。容器结构边界与淡色虚线辅助网格分开处理。
- 统一展示状态和单位工具入口为web/shared/units.js，预算页number-format.js保留兼容入口。现有服务普通刷新即可取得内容指纹新资源，无需服务重启。
- 中心视觉专家instructions/preferences更新为0.7.4并回读，共享环境变更已提交。未对无关项目全面分发，未将源文件更新等同于所有宿主已加载。

## 验证

- 既有全量回归491项通过；新增数值精度测试通过，最终相关测试10项通过（含9项既有导航测试）。主题生成同步检查通过。
- A/B/SPAD/预算未编辑表单采集结果与各自源工况深度比较均无差异；C的90个数值字段逐项核对导出无差异。
- 五个平台1920×950截图及明暗检查，B/SPAD/预算/C额外检查1536×760与1280×620，无整页横向溢出，五个平台入口齐全。A窗口实际交互检查通过。
- 主模型实际看图，视觉专家复审B明暗、A时间窗口、SPAD/C/预算浅色，认为分层问题已解决，无必须修正点。
- 初次browser-report记录C现有大规模默认计划超出投影工作限额；仅在自动化浏览器草稿中减小列数和探测规模，最终C轻量计划校验通过，截图为该测试草稿，未写回默认值。此既有模型/资源约束未由本轮关闭。
