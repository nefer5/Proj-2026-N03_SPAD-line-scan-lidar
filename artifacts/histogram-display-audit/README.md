# 机制字体、直方图纵轴与峰值损失核验

工况：`07814a948d114a18bcda2d666b84ca10`，CH04 / H0 V4。原始任务文件未修改。2026-09-25。

## 界面修改

- 机制卡片的数值与单位分开排版。“发、次、μs、ns”统一使用页面无衬线字体、12 px；等宽字体增加显式中文回退，避免中文落到另一套字形。机制SVG标签同样使用页面字体。
- “统一纵轴”此前仅统一多个通道在当前窗口中的范围；单通道看不到统一效果，平移窗口仍会重新缩放。
- 新“统一纵轴 · 全门固定”取当前选中通道、图层及采集范围的全门最大值，平移/缩放观察窗口保持纵轴；取消勾选则各通道局部自适应。切换gate/slot、通道、图层或重放分箱会重新确定范围。
- 网格位置本身改为整数计数，并使用整数步长；不是仅把小数标签四舍五入。
- 图例和说明明确青线是死时间前的纯信号参考，不是预计最终输出。

## 同候选事件对照

从保存的光谱、物理像素照明、工况和seed=7重建候选流，先逐条复现原始采集记录。然后保持完全相同的候选流和电子随机种子，仅将SPAD死时间从11 ns设为0，使用同一公共采集核心：

- 原slot蓝柱峰值：67。
- 零死时间对照的slot峰值：222。
- 原全阵列：28240个候选事件，8875个因SPAD死时间丢失，19365条记录。
- 两组的TDC死时间损失、容量损失均为0。
- CH04全门：22676个候选事件，8003个因SPAD死时间被拒绝。
- 理想散点峰所在[667,668) ns分箱内，CH04跨8发共有223个候选事件，仅48个通过SPAD状态检查，175个被死时间拒绝。这里按电子抖动前的雪崩时刻计数，不等于最终分箱计数。
- 原实际蓝柱峰位于666.5 ns，比理想散点峰667.5 ns更早，符合早到事件先占用器件、后续事件被压低的机制。

每通道32个SPAD，11 ns恢复时间明显长于2 ns FWHM脉冲。同一物理像素的多个候选不能都记录；背景也会提前占用器件。死时间既降低幅度，也改变波形。零死时间对照包含背景与随机采样，不能要求它精确等于纯信号解析曲线。

诊断没有修改生产配置或用户数据，也没有据此估算检测SNR。电子抖动在被接受的记录上抽样，因此改变接受事件集合后，同一电子seed不代表每个存活事件仍获得相同抖动值。
