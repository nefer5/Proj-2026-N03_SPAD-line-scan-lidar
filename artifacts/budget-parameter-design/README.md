# 参数配对分组审核预览

状态：画板设计及标题层级已获用户确认；正式网页已接入并按后续要求压缩输入高度。实际实现与验收见../budget-parameter-live/README.md。画板文件保留为设计原件。

## 方案

- H/V对应量必须在同一分组框内，固定左H、右V，统一标题和单位。独立量单列，其他组合按语义标注，不机械配成两列。
- Rx：角域H/V；入瞳形状与对应几何；焦距H/V；PSF标准差H/V；接收效率单独；gate起点/宽度同组，固定标定延迟另列。
- SPAD：H/V binning同组并显示派生cell总数；pitch显示派生H/V完整尺寸；FF单独；时间响应/数字读出按物理角色归组。
- 系统目标：HFOV/VFOV与slot/线数两组，派生采样步距和单通道V角域在对应组下方。
- Tx、MIPI、距离参考使用同样的语义分组；形状或输出模式决定有效字段，未使用字段不占位，切换时保留其原输入。
- 模块可折叠并保留成对摘要，既有全部收起/展开保留；分组不再新增一层折叠。窄屏可改为组内竖排，但不能拆散分组。

示例值来自既有current-audit.json，只用于预览，不复制为运行默认值。画板内各文字、边框均为可编辑元素，截图只作显示证据。
