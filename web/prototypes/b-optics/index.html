如何理解理想曲线和误差棒？

蓝柱是一次含噪采集；青色散点是各 bin 内的纯信号解析积分，虚线是连续计数密度 × bin 宽。青色已包含 PDE / FF，不含背景、死时间或读出损失。橙线来自关闭激光的独立重复采集。误差棒是逐 bin 样本最小—最大值，不是置信区间；包含首次蓝柱。

这里的统计数组由现有 Python 核心离线生成。页面缩放、选通道和切换图层只改变显示。

位置映射、PSF 与响应矩阵

位置映射分别使用 f_H / f_V，并计入两轴倒置。矩阵 P 的每一列是一个入射角单元在各像素内的积分份额，D 包含 Rx 效率和滤光透过率，q 是入瞳各角单元的光子数。n 位于 PDE / FF 前。分组矩阵 G 将像素光子汇总为通道光子；SPAD 死时间和读出限制继续由事件模型处理。

05 / CHANNEL LEAKAGE

所选角单元 · 光学串扰 / 通道比值

η 是同一入射角、同一波长下落入通道的光学能量份额。使用功率 / 能量比的 10 倍对数；幅度平方对应功率时，幅度比才使用 20 倍对数。此处不使用幅度定义。

按通道空间布局

相对所选参考 · dB

当前角单元的通道间比值矩阵

行：观测通道 / 列：参考通道

单个入射角提供一组通道响应。本矩阵比较这组响应的通道间比值，不代表逐个输入通道独立激励得到的完整串扰传递矩阵，也不包含雪崩串扰。

参考通道有响应时为 0 dB；更弱为负，更强为正。分子为零显示 −∞；参考通道为零显示“未定义”。不加微小数、不静默截断；浮点下溢得到的零也不代表实测绝对无串扰。
