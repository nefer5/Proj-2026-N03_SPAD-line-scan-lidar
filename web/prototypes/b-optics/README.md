# B 空间光学：前端设计原型 02

预览：`http://127.0.0.1:8015/static/prototypes/b-optics/index.html`

用现有启动器启动服务：`python run.py --port 8015`。这是独立的静态原型入口，没有改动正式 A / SPAD / B / C 页面、API、配置类型或数值模型。

## 可体验内容

- 七个物理参数分组、青色标题、小尺寸全折叠/展开、展开状态保存。
- H/V × 中心/宽度、H/V × 最小/最大值的结构化表单。
- 环境光统一分类；PDE 和滤光片编辑器归入所属模块。
- 本地参数草稿、恢复样例、草稿导出；改动后明确提示图表仍为固定样例。
- 紧凑任务栏、可展开的概念说明与信号链示意。
- 带单位、坐标、色标及真实坐标纵横比的二维图。
- 通道点选 / 编号范围输入、多通道分面、局部窗口、全门概览及图层开关。
- 二维角度点选，与像面 PSF、通道份额及边缘损失联动。
- 固定样例直方图 CSV、所选角单元响应 JSON 导出。
- 分开的 f_H / f_V 草稿输入；两轴倒置成像，所有空间图上正下负。
- 可折叠基础参数可视化：Tx 时间脉冲、滤光片、太阳辐照度、太阳反射与其他环境光合成、PDE/FF、滤光片×PDE×FF、Tx角分布、Rx H/V映射、PSF剖面、采集时序。
- 所选角单元的相对通道 dB 分布、条件通道比值矩阵、参考通道选择及导出。

点击“运行仿真”会明确说明尚未接入计算，不会提交任务。表单只用于界面评审，完整的物理参数校验、配置迁移、生产组件整合、可编辑重复次数和后端重算留待后续实现。

## 数据来源

`snapshot.json` 是 Python 核心的结果快照，不是新的默认值定义。`tools/build_b_ui_preview.py` 通过 `SimulationConfig` / `Algorithms` 读取唯一 YAML 配置，调用已有 B 光学投影和事件采集。02版对同名、同物理含义的共有参数完整继承 A 默认值，包括原来的1发、开启太阳和其他环境光；不再采用01版专门的100发无环境光演示覆盖。原型没有修改正式 B/C 的配置预设。

新 f_H/f_V 的初值均从 YAML 中原标量焦距派生，没有在 HTML/JS 中定义新的数值默认值。正式配置类型尚未迁移；当前固定样例通过现有 Rx 数据库适配器，在负的输入角度查询现有高斯积分核心，生成两轴倒置响应。样例的两个焦距相等，草稿可分别修改但不会重算。旧适配器的坐标约定标签暂保留用于兼容，倒置约定及上正下负的显示方式单独写入样例溯源。生产模型的几何公式与坐标契约升级留待后续实现。

离线生成的数据包括：

- 一次实际 B 采集；
- YAML 中指定次数的独立重复采集（包括首次观测），用于逐 bin 最小—最大范围；
- YAML 算法设置中指定次数的关激光采集均值；
- 按 B 各通道实际入射光子预算调用 A 的公共纯信号解析参考函数；
- 各角单元经现有 Rx 插值得到的像素积分 PSF。

前端只渲染上述数组，不实现物理波形，也不计算 dB 比值。基础配置曲线复用初版的 `derived_quantities` 等公共 Python 数据源。原始统计数组、种子及首次采集保存在 `artifacts/ui-prototypes/b-optics-v2/`。光学工况是构造样例，不表示实测系统。

## dB 定义

固定入射角单元下，行是观测通道，列是参考通道。dB值取“观测通道能量份额 / 参考通道能量份额”的10倍常用对数。页面公式本体集中在 `preview-panels.js` 的 `previewFormulas`，由本地KaTeX渲染。

η是光学能量份额，参考面在PDE/FF之前。分子为零、分母非零时导出`-inf`；参考通道为零时导出`null`表示未定义。无epsilon替代或数值截断，浮点下溢的零不代表实测绝对隔离。幅度比的20倍对数仅适用于功率与幅度平方成正比的对应定义。

这个条件比值矩阵来源于同一个入射角，不是逐个输入通道独立激励得到的完整串扰传递矩阵。也不表示SPAD雪崩串扰。
